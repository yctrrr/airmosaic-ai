# 设计排放核算

[English](SKILL.md) | **中文**

[方法](../../../../methods/02_emission_inventory/emission_accounting_ZH.md)说明科学边界、活动/技术/治理定义、候选数据来源与不确定性。本入口现提供经合成输入验证的直接 Python 计算器，稳定技能名不变，**没有注册工具 ID、run-tool 或 MCP 适配器**。空间分配仍是独立的概念/适配路径。

## 使用步骤

1. 声明地区/年份、活动及物料或能源口径、部门/过程和污染物表达。真实数据准备前确认授权来源与输出范围。
2. 将活动、技术活动份额、**未治理**因子、互斥治理路线四表整理为显式 JSON，区分安装覆盖、有效活动量加权运行、捕集与污染物去除。
3. 检查占比完整、键唯一、单位/基准兼容、因子/路线覆盖及来源，不猜缺少的路线、不自动归一化份额、不重复扣减因子已包含的治理。
4. 按[配置与调用](references/operations_ZH.md)先用直接脚本自己的 `--dry-run`，再执行到新的授权外部结果目录。这不是执行器预检，也不构成操作系统沙箱。
5. 检查技术/路线排放、分污染物汇总、输入/产物哈希及质量平衡，交接前报告科学限制及真实数据适配项。

[完整示例](examples/inventory.synthetic.json)的活动、因子和治理参数全部人为构造，预期剩余排放为 SO₂ 24,664 kg、NOx 30,960 kg，仅作算术验证，不是观测或真实清单。[操作说明](references/operations_ZH.md)提供可运行命令和产物检查。2026-10-30 的 21 项合成实现测试通过，覆盖数值/单位、非法份额/输入、输出不覆盖、Git 边界和链接输入拒绝。没有读取真实数据或凭据，也没有使用 MEIC 来源。

计算器只读取一个明确指定的本地 JSON，不发现数据、不下载、不安装包、不访问凭据。真实整理输入和结果保存在获授权的外部资产，个人路径映射及凭据分离。来源只读、已有输出拒绝覆盖，日志不输出个人绝对路径。详细结果仍可能含敏感来源标签，共享前需复核；数据解释与授权由调用方负责，检查不等于完整执行器隔离。

首版不做含治理因子/CEMS 核算、多串联设备联合运行推导、空间/时间/组分拆分、因子获取或不确定性传播。[空间清单方法](../../../../methods/02_emission_inventory/spatial_inventory_ZH.md)解释后续交接。[外部参考](references/sources_ZH.md)记录核对过的技能组织和一手科学来源，没有复制或安装第三方代码。
