# 地理编码：本地来源与服务选择

[English](geocoding.md) | **中文**

这里是获取与质量流程，不是已启用的地理编码 API。先区分地址转坐标、逆地理编码和点与行政区匹配；一项结果不能自动验证另一项。

## 服务选择与隐私

任务适合时优先采用获授权的本地地名表或机构服务。在线编码会向第三方发送地址或位置，用户明确授权的在线任务可以规定该范围，无需为同一获准动作重复询问。住宅、患者、雇员或保密地点不能在没有适当许可的路径下提交。私人查询、精确返回坐标和缓存留在 Git 外。

**公共 Nominatim 不是通用代理地理编码的默认服务。** 其[当前政策](https://operations.osmfoundation.org/policies/nominatim/)要求开发者作出知情选择，限制工作量（公共服务器最高每秒一次，批量另有限制），要求标识/署名和缓存，禁止个人/保密资料、自动补全与系统性提取。通用技能不能静默把它接成地址服务。自建或其他提供方按各自条款使用，客户端库不能替代服务条款。

[geopy](https://geopy.readthedocs.io/en/stable/) 与 [tidygeocoder](https://jessecambon.github.io/tidygeocoder/articles/tidygeocoder.html)提供多服务的正向/逆向客户端方法。编写任务适配前，选择服务、端点、地区/语言、限速、重试预算和允许的缓存规则。二者都不是通用免费后端，本技能未实测在线服务。

## 使用流程

1. 保留来源行标识、地址来源/日期和所需精度，记录拼写/空格规范化，不随意删除有效建筑或地域信息。
2. 可行时先用获许可的本地地名表。同名需要地域上下文并保留候选，零匹配维持缺失。
3. 在线路径获准后，按服务接口从个人受保护机制使用凭据，只发送必要字段，应用当前额度与有界重试。不记录含密钥的请求 URL、私人查询文字或原始认证错误。
4. 保留候选坐标、坐标约定、提供方/版本、返回精度/类型、地区一致性和人工状态。不同服务的置信分数不可直接比较，也不自动表示米级误差。
5. 多个合理候选、国家/地区异常，或站点任务只返回城市中心时应拒绝或复核，不能据弱匹配制造站点坐标。
6. 使用版本明确的边界单独验证所需空间关系。审核后才保存新的外部版本，不自动入库或覆盖来源。

## 不同语言路径

| 操作 | R 路径 | Python 路径 |
|---|---|---|
| 本地地名表 | 对准备表显式按键连接并计算候选数 | pandas 连接，保留键与候选数 |
| 正向查询 | 按服务配置 `tidygeocoder::geocode` / `geo` | 所选 geopy 服务的 `geocode` 方法 |
| 逆向查询 | 按服务配置 `reverse_geocode` / `reverse_geo` | 所选服务的 `reverse` 方法 |
| 行政归属 | R 包含匹配函数，使用已知坐标系和审查边界 | 同一契约下的 Python 包含匹配函数 |
| 服务坐标转换 | 单独审查的提供方接口 | 单独审查的提供方接口 |

没有默认服务、隐藏密钥加载器或通用联网执行器。在线适配在完成验证与注册前仍属于具体任务。[高德坐标接口](https://lbs.amap.com/api/webservice/guide/api/convert)说明了另一种服务合同，不是普通 EPSG 变换，也不是这里已实现的服务。

## 最小记录

私人任务表保留来源标识、查询分类、来源/服务版本、候选数、返回精度、坐标约定、处理/审核状态和缓存规则。密钥与会话另存。共享汇总可报告总体匹配率与检查方法，并移除个人查询文字及敏感坐标。
