# 配置空气污染任务

[English](air-pollution.md) | **中文**

先按[面向读者的特例](../../../../../methods/shared/air_pollution_regression_ZH.md)选择科学设计，再映射到以下设置。环境、配置生成代码及调用方式统一维护在[操作说明](operations_ZH.md)。

## 浓度预测

从完整的 [PM2.5 任务模板](../../../../../config/examples/ml-regression/air-pollution-prediction.template.json)开始。它接收已整理的站点日表，使用以下示例列：

| 角色 | 模板字段 | 需要适配 |
|---|---|---|
| 结果 | `pm25` | 实际污染物统计量、单位及平均时期 |
| 样本键 | `sample_id` | 唯一站点时期标识 |
| 划分 | `dataset` | 按研究设计生成的 `train`、`val`、`test` 标签 |
| 数值特征 | `temperature`、`relative_humidity`、`wind_speed`、`boundary_layer_height` | 时空对齐且符合使用时点的列 |
| 类别特征 | `season` | 实际类别列，在 `categorical_features` 声明 |

按所选数据适配字段、类型、缺失标记、覆盖规则和划分。连接、单位转换、汇总及派生变量在上游完成。模板用于回顾分析，预报任务应重新定义信息可获得性。

将未观测时空区域的预测目标与这份带标签站点表分别定义。完成[输入依据检查](operations_ZH.md#核对输入依据)，包括再分析、融合、合成特征使用地面观测及重用评估站点、时期的情况。记录未知来源及所选独立参照或敏感性策略。该模板不实现区域推理和场数据导出。

初始候选为深度 5 的树，以及 `mtry=2`、节点大小 5 的 100 棵树森林，用于小规模起始比较。`selection_metric` 选 RMSE 或 MAE，在四个候选限制内比较其他支持设置；确认 `mtry` 适合保留变量数。

按研究可用数据和独立站点、时间覆盖确定划分规模。模板采用执行器支持的最大行数上限，避免继承小规模演示数量；这些是上限，不是要求的样本数或比例，执行前须结合实际队列和预算检查。更大研究按操作说明决定规模适配或抽样。

同时检查训练中位数/众数策略和解释预算，按预期队列调整上限，并查看实际选中数量。筛选选择 `manual` 或 `train_filter`，固定候选顺序；解释选择 `permutation`、`pdp`、`ice` 和可选 `shap`，科学含义按方法说明理解。

模板没有配套数据。验证代码调用可用[合成参数](../../../../../config/examples/run-tool/synthetic-regression.json)，其结果、特征与单位均为合成。

## 连续驱动效应

用完整[合成 PLR 任务](../../../../../config/examples/ml-regression/synthetic-causal.json)理解接口。真实研究先论证专用图和调整集，再替换以下字段：

| 决策 | 配置 |
|---|---|
| 分析与结果 | `analysis=causal_plr`、实际 `target` 和 `target_unit` |
| 处理对比 | `causal.treatment`、`treatment_unit`、`treatment_scale` |
| 调整 | `features=causal.adjustment_set`、`feature_selection.mode=manual`；处理不作预测变量 |
| 缺失与学习器 | `missing.policy=drop`，恰好一个辅助模型候选 |
| 折分设计 | `causal.folds`、`resampling.mode`，分组模式再填 `group_column` |
| 识别 | `causal.dag` 和经过论证的六项 `causal.assumptions` |

分支对保留的训练与验证数据进行交叉拟合，系数表示每 `treatment_scale` 个原始处理单位对应的结果单位变化。通过因果产物检查图有效性、折外隔离、处理残差变异和不确定性。分组折分保留组身份，组间独立仍需研究设计论证。

声明假设前，记录各变量对应的物理量或代理量、因果方向依据、混杂与中介、产品生成依赖及合理的备选解释，对未解决假设安排敏感性检查。DAG 检查通过或系数精确，不足以说明因果关系可靠。

现成[合成因果执行参数](../../../../../config/examples/run-tool/synthetic-causal.json)可按与预测相同的 CLI 顺序验证该分支。预测重要性输出不能替代这组配置。

## 下游影响与适配

支持的数值影响预测仍使用同样的目标、特征和划分字段，拟合前确定暴露匹配、滞后、结果分母及因果识别。需要气象归一化、非线性暴露响应、专用计数/二元/生存模型、分布滞后或负担计算时，先确定缺失操作，在相应技能实现后再组合工作流。
