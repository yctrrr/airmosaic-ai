[English](SKILL.md) | **中文**

本序列参考归入上层[机器学习能力](../../../SKILL_ZH.md)。适配代码前先阅读[对应的人类方法说明](../../../../../../../methods/shared/machine_learning_model/models/time_series/timexer/README_ZH.md)。

## 配置任务

已核对的源码提交和依赖见[上游记录](UPSTREAM.md)。源码保存在本仓库外，通过 `TIMEXER_SOURCE_DIR` 引用，使用独立 Python/PyTorch 环境。

| 设置 | 需要明确 |
|---|---|
| 目标与时间 | 目标列、采样频率、预测起点和提前量 |
| 输入 | 按时间排序、规则采样、包含日期列和数值变量的 CSV；每条序列属于同一实体 |
| 角色 | `MS` 为多变量历史、单目标输出，`M` 为多变量输出 |
| 窗口 | `seq_len`、`pred_len`、`patch_len`，保证历史足够和目标片段整除 |
| 模型与预算 | 维度、注意力头、层数、批量、轮次、工作进程与设备 |
| 保存 | 固定输入版本与新的外部项目结果目录 |

## 使用代码

[使用方法与命令示例](references/usage_ZH.md)提供完整的上游 `run.py` 调用、依赖和输入检查。先使用足够长的合成历史，在新项目结果目录启动，使相对路径的权重、预测及日志保存在其中。

1. 检查时间戳、缺口、数值类型、目标顺序及仅训练范围的缩放。
2. 按采样点设置历史和预测长度，再选择兼容的模型维度。
3. 训练前审查现成时间划分及验证准则。
4. 保留配置、权重、缩放器、特征顺序和时间编码。

已跟踪模型使用历史输入，已知未来协变量、混合频率及多实体需要数据或模型适配。现成基准训练时会输出测试误差，独立最终测试协议需显式处理。

## 检查结果

核对预测起点、提前量、形状、有限数值、目标单位和逆缩放；与持续性或季节性基线比较，按提前量和实体检查误差。保留权重身份和实际训练环境。

`--is_training 0` 执行带标签测试，不是仅历史输入的部署推理。使用无标签新批次前，先实现和验证缩放器复用与历史输入契约。种子、设备及权重路径的版本细节见使用参考。
