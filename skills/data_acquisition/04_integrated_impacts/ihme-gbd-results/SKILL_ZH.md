# IHME GBD 结果获取

<!-- README-I18N:START -->

[English](SKILL.md) | **中文**

<!-- README-I18N:END -->

> 调用状态：`ihme_gbd_fetch_results` 已接入 `run-tool`，需要已有、经授权的本机回环浏览器会话。工具不负责启动浏览器或登录。

来源、误差、数量与率、年龄及不确定区间见[数据方法](../../../../methods/04_integrated_impacts/ihme_gbd_ZH.md)。首次使用按[获取向导](references/first-download-guide_ZH.md)操作，分别核对网页访问、新结果、文件取得及工具执行。

产品选择见[数据范围与下载计划](../../../../methods/04_integrated_impacts/ihme_gbd_availability_ZH.md)。风险、暴露、人口和生命表需核对专用入口。现有适配器没有独立风险或其他专题编号参数，不能只修改 `context` 就认定支持。

## 可下载的数据

GBD 2023 疾病与风险估计主要覆盖 1990–2023 年。轮次、地区、年龄及指标组合以当前产品记录为准；人口学与专题产品的年份分别核对。来源依据见[范围说明](../../../../methods/04_integrated_impacts/ihme_gbd_availability_ZH.md)。

| 数据 | 常见输出 | 获取入口与项目状态 |
|---|---|---|
| 病因死亡 | 数量、率及适用的比例 | 结果工具的病因入口；全球全因死亡数量单条导出已验证 |
| 过早死亡损失寿命年 | 数量、率 | 病因入口；工具可传度量参数，尚未逐项验证 |
| 伤残生存年 | 数量、率 | 病因入口；尚未逐项验证 |
| 伤残调整寿命年 | 数量、率 | 病因入口；尚未逐项验证 |
| 发病与患病 | 数量及适用的率、比例 | 病因入口；病因与年龄组合另核 |
| 风险归因负担 | 归因死亡、疾病负担及适用的人群归因分值 | 风险入口；需人工网页操作或补充风险参数适配 |
| 汇总暴露值 | 风险暴露指标 | 专用选项；需单独核验，不能作为 PM2.5 浓度使用 |
| 健康预期寿命 | 健康生存年数 | 专用选项；需核对产品维度 |
| 全因死亡与预期寿命 | 人口学死亡率、预期寿命 | 对应轮次的数据目录产品；分别核对 |
| 人口、生命表与生育 | 年龄、性别人口及生命表、生育指标 | 结果工具导航或数据目录；尚未验证工具导出 |
| 其他专题 | 病因学、损伤性质、功能损害等适用结果 | 按专题入口选择，工具需要补充专用参数 |

下载前固定轮次、年份、地区、病因或风险、年龄、性别、度量及量度。先验证少量组合，再按明确任务扩大，不默认下载全部组合。数量、率和比例分别保存，保留产品提供的 `val`、`lower`、`upper`。

## 工作目录与认证

遵守[存储约定](../../../../harness/storage-and-credentials_ZH.md)和[执行指南](../../../../harness/usage/run-tool.md)。仓库外的三个根目录须相互独立且已存在：`AIRMOSAIC_LOCAL_WORKSPACE` 存数据与结果，`AIRMOSAIC_CONFIG_DIR` 存非秘密设置及任务参数，`AIRMOSAIC_AUTH_DIR` 存本人浏览器状态。密码和令牌保存在秘密管理器中。

不读取或分享凭据、浏览器配置内容、会话信息及私人路径。仓库命令从仓库根目录运行，使用安装项目的解释器。工具默认分配 `output/<run_id>/<tool_id>/`，没有任务需要时省略输出参数。个人配置不自动加载。直接执行脚本会绕过检查；执行器不是操作系统沙箱。

## 用途

用于限定范围的数据获取与本地处理。技能不保存凭据、会话、浏览器配置或私人路径；原导出和派生死亡表留在工作区。

## 结果与缓存边界

工具输出 `output/<run_id>/ihme_gbd_fetch_results/results.csv` 及关联 JSON 文件。将验证后的导出发布到 `${AIRMOSAIC_LOCAL_WORKSPACE}/data_cache/gbd_health/` 是另行授权的操作，不是执行器的自动行为。不提交导出、账户身份或浏览器产物。

## 工作流程

1. 打开官方结果工具，由本人决定条款并完成登录和验证。
2. 核对当前轮次及全部维度，先使用[首次向导](references/first-download-guide_ZH.md)的单条样例。
3. 选择下述网页下载流程，或先核验本任务的本机回环调试会话再使用注册工具。普通网页下载不要求开启调试端口。
4. 注册工具统一通过 `run-tool` 调用。不直接执行原脚本绕过检查，也不使用内部接口替代被阻止或过时的网页结果。
5. 原始导出与项目派生表分别保存；两条路线都不会自动发布缓存。
6. 显式映射编号、名称和本地结构，不按排序猜测病因或年龄映射。
7. 按键和值对照源表验证派生表，遵守[检查清单](references/processing-validation_ZH.md)。

## 网页下载步骤

1. 打开[官方结果工具](https://vizhub.healthdata.org/gbd-results/)，由本人处理条款、登录及访问验证，完成后返回查询页。不索取凭证或账户截图。
2. 核对全部条件。首次使用：GBD 2023、2023 年、全球、全因、全年龄、两性合计、死亡、数量，预期一条记录。
3. 提交一次搜索并等待本次新结果。验证提示交给本人完成；不使用加载中或报错后的旧表。
4. 点击“下载”，选择“双”，同时保留编号和名称。此处是导出字段设置，与性别的“两性合计”不同。核对范围后提交一次。
5. 点击成功提示中的“在此处监控进度”。出现“您的下载已准备就绪”后，从数据文件链接取得压缩包。也可由本人使用邮件链接，代理无需读取邮箱。有效期以当前页面为准。
6. 原压缩包放在工作区 `output/<run_id>/ihme-gbd/raw/`。检查归档完整性、表格字段、编号与名称、年份、唯一键、行数及数值，确认 `lower ≤ val ≤ upper`。派生表放 `processed`，摘要放 `quality`，不发布原文件或任务链接。
7. 在 `runs/<run_id>/` 记录查询核对、导出提交、文件取得及检查完成的实际时间。非秘密参数放个人配置目录，认证放认证目录；私人记录不写入共享说明。

**已验证样例**：2026-10-26 北京时间 21:05:42 完成单条网页获取与内容检查，压缩包 717 字节，其中一份表格、一条记录、18 列。详细时间和返回编号见[实测向导](references/first-download-guide_ZH.md)。真实工具调用仍待任务调试会话核验。

后续可选择中国、2019/2023 年、缺血性心脏病、全年龄、两性合计、死亡、数量和率，最多四条记录。此计划及[候选健康基线计划](../../../../methods/04_integrated_impacts/ihme_gbd_availability_ZH.md#建议的分级下载范围)均未执行。

## 执行器的浏览器配置

使用本地配置的浏览器程序，以及 `${AIRMOSAIC_AUTH_DIR}/browser_profiles/ihme-gbd/` 下的本人浏览器配置，由本人登录。调试端点只监听本机回环地址，端口属于当前任务，连接前核对归属。

程序映射放个人配置目录。不提交程序路径、浏览器配置路径、会话或账户身份。完整流程见项目分类获取指南。

## 注册工具的调用

先查询 `ihme_gbd_fetch_results`。[公开参数示例](../../../../examples/run-tool/gbd.json)和 `examples/gbd_mortality_rate_request.json` 仅展示历史语法。核对当前版本和维度编号，将非秘密参数保存到个人配置目录，然后预检；确认参数和授权会话后再执行。

```powershell
python -m airmosaic_core.cli describe-tool ihme_gbd_fetch_results
$gbdParams = Join-Path $env:AIRMOSAIC_CONFIG_DIR "gbd-task.json"
python -m airmosaic_core.cli run-tool ihme_gbd_fetch_results --params-file $gbdParams --dry-run --allow-network --confirm-browser-session
python -m airmosaic_core.cli run-tool ihme_gbd_fetch_results --params-file $gbdParams --allow-network --confirm-browser-session --timeout 300
```

必填字段为 `years`、`locations`、`causes`、`ages`、`sexes`、`measures`、`metrics`，均使用逗号分隔的数字编号字符串，如 `"ages":"10,11"`，不使用数组或冒号范围。可选字段包括整数 `port`、`version`、`population_group`、`wait_ms`，以及字符串 `context`。`out` 默认自动分配。参数不得包含凭证或浏览器配置路径。

`--allow-network` 允许声明的网络操作；`--confirm-browser-session` 声明调试端点属于本任务，不验证登录或编号含义。工具不启动浏览器、不登录、不导出认证状态。核对表格与关联 JSON 的维度、行数和错误；退出码为零不等于导出完整。报错后不沿用旧表。

## 版本与编号检查

历史默认值包含版本 `8352`、上下文 `cause`、人口组 `1` 和端口 `9222`。使用前核对当前含义，不会自动映射到最新轮次。

区分数量、每十万人率和比例。编号格式检查不证明该组合存在或适用。年龄映射和人口分母需要明确对照，不能按排序推断。

## 处理规则

项目专用处理保留在调用项目中：

1. 研究期优先使用同一轮次，不按旧项目年份切点拼接不同轮次。
2. 必须跨轮次衔接时，说明估计修订、方法和明确映射。
3. 未授权迁移时保留既有输出结构。
4. 不适用的低龄病因组合保留缺失，或使用有依据的方法。
5. 缺失组合报告及来源摘要与主表分开。

## 代理执行边界

执行器任务只使用 `ihme_gbd_fetch_results`，本人会话须已准备。子进程使用最小环境，但脚本仍依赖网页内部状态，页面变化可能需要适配。重试前核对错误及部分输出，本地保留源表到派生表的追溯关系。

## 检查清单

- 对照源表和派生表字段。
- 核对年份及行数。
- 检查非预期缺失。
- 显式映射后，按适用键核对派生值与源值及数值容差；项目别名不是默认源字段。
- 列出派生表存在而源表缺少的组合。
- 确认共享文件没有凭据、会话或私人浏览器路径。
