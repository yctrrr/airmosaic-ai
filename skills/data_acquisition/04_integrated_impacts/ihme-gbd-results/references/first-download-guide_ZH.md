## 1. 打开官方页面

1. 打开 [官方结果工具](https://vizhub.healthdata.org/gbd-results/)，核对官方域名。
2. 若显示使用条款，由本人阅读并决定是否接受；若需登录/注册或验证，由本人完成。不要把密码、验证码、截图中的账户资料或令牌发给代理。
3. 完成后返回查询页面，再由代理读取公开筛选控件。登录页面操作期间暂停页面读取；无需导出会话信息或复制已有浏览器配置。
4. 核对页面显示的 GBD 轮次；数据年份由筛选项另选。不能仅因看到查询框或旧结果，就宣布新查询或下载已经可用。

## 2. 单条记录的查询样例

本轮使用标签已经核对的最小范围：

| 条件 | 选择 |
|---|---|
| 网页显示轮次 | GBD 2023 |
| 估计类型 | 死亡或受伤原因 |
| 度量 | 死亡 |
| 量度 | 数量 |
| 原因 | 所有原因 / 全因 |
| 地区 | 全球 / 全球 |
| 年龄 | 全部 / 全年龄 |
| 性别 | 两性合计 |
| 年份 | 2023 |

1. 检查多选框的**全部已选项**，移除额外度量、指标和地区，不只看搜索输入中的文字。
2. 下拉项应按可读标签选择；不得用历史 ID 或排序猜测当前选项。没有返回选项时，先核对页面状态，不据此虚构地区/病因映射。
3. 核对全部条件后提交一次搜索。中文界面的“度量”和“量度”分别对应 measure 与 metric，易混淆，应一起记录英文含义。
4. 等待加载结束，确认新表恰有预期的单条维度组合，并保留点估计及上下界。旧表如仍含 DALYs、百分比或率，与本例不符，不能直接验收。
5. 加载超时或出现错误时记录状态，先核对原请求；不要连续提交、盲目刷新或将旧表另存为“新结果”。本人可检查是否另有登录、验证或条款提示。

出现访问验证（如 Verifying your request）时由本人完成，代理暂停该查询的进一步操作；不自动解题、不绕过保护、不通过内部接口替代验证。

## 3. 导出与本地检查

1. 在新结果的维度核对通过后点击下载。下载对话框选择“双”，同时保留维度 ID 和名称；核对请求范围。如果另有条款或验证，由本人完成。
2. 提交一次导出请求。页面提示成功后，点击“在此处监控进度”，无需读取本人邮箱；也可由本人使用平台发送的邮件链接。
3. 等待进度页显示“您的下载已准备就绪”，点击“IHME 数据文件”下的下载链接取得 ZIP。本次页面提示文件创建后 7 天内可下载，实际以当次页面为准。
4. 将新取得的文件保存到 `AIRMOSAIC_LOCAL_WORKSPACE/output/<run_id>/ihme-gbd/raw/`，保留 ZIP 原件。核对该次请求的文件，个人邮件、任务引用和临时下载链接不进入公共说明。
5. 非秘密计划保存在 `AIRMOSAIC_CONFIG_DIR/gbd/`，运行状态与取得时间在工作区 `runs/<run_id>/`。检查 ZIP 完整性、CSV 实际列名、ID/标签、单位、记录数、重复键、缺失和区间顺序；校验摘要另存 `quality`。
6. 转换另存 `processed`；没有实际落盘和内容检查，就不标记“导出验证通过”。

操作开始、提交、完成/失败和文件验收分别记录真实北京时间；尚未发生的步骤留空，不填写预计成功时间。

## 4. run-tool 的独立前置条件

已有 `ihme_gbd_fetch_results` 需要任务已授权的本机回环调试端口及当前页面参数。内置浏览器可操作不等于 `127.0.0.1:9222` 已存在；不扫描其他会话、打开任意调试端口或复制认证状态。

在独立浏览器已经由本人/管理员准备、端口归属已核验后，才能按 [SKILL_ZH.md](../SKILL_ZH.md)进行工具预检和真实调用。会话声明只表示归属确认，不证明登录成功；仅检查安装依赖或预检返回 0 也不证明真实导出可用。

当前脚本依赖网页内部状态接口，页面升级可能需要适配；保留默认版本号等历史语法，不将其当作已核验的当前映射。未确认调试端点与参数前，不执行原脚本或内部 PHP 请求来绕过这些条件。
