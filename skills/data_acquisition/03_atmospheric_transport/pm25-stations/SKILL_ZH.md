**状态：参考。** 提供来源选择、直接下载和整理流程；已验证公开单日 CSV 的小时 PM2.5 长表，以及 PANGAEA 均一化发布包和 7 天小样例。没有可执行脚本、注册工具 ID、数据集声明或 run-tool dry-run。不能把 技能名称、来源标识或旧脚本名作为工具 ID。

## 先确认任务边界

- 文档维护、来源梳理和接口设计：只查看相关说明、接口和文件清单，不打开监测原始表、坐标表或模型结果。存在文件不等于来源、覆盖和质量已经核实。
- 获取任务：用户须明确监测网络、日期、污染物、站点范围和目标位置；依已有任务授权执行，不因阅读本技能 获得批量下载授权。
- 整理任务：用户须明确允许读取的输入、输出范围和统计口径；获取授权不自动扩展为汇总、补值或模型运算。

## A. 获取流程

先选择产品：

- **小时发布归档**：按[单日获取与整理示例](references/single-day-example.md)取得公开站点 CSV，核对类型、缺失和原时间标签。
- **均一化日值**：先读[产品方法说明](../../../../methods/03_atmospheric_transport/pm25_homogenized.md)，再按[PANGAEA 获取示例](references/homogenized-download-example.md)取得指定发布包。保留 `S0001` 一类产品序列标识，不能冒充原国控站号或反推有效小时数。

两条已验证路线均不需要账号或 接口密钥，各示例记录正确流程、结果和操作时间；原始发布值与已填补/调整的日值分开管理。

1. **定义观测产品**：确定监测网络、站点或城市、小时或日尺度、原始/已质控发布观测或均一化产品。AQI 不是 PM2.5 浓度，网格估计也不是站点实测。
2. **选择来源**：按[来源与格式](../../../../methods/03_atmospheric_transport/pm25_stations_sources.md)核对官方发布、第三方历史归档或研究产品。记录原发布机构、实际提供者、产品版本和许可；不从本地文件名反推来源。
3. **准备非秘密计划**：列明日期批次、站点表版本、单位、时区和时间标签、预期文件、请求数量、目标相对位置、缺失处理及验收方式。未确认字段显式标为待核实，不默认套用 UTC 或固定有效小时门槛。
4. **人工获取或适配渠道**：在已有明确下载任务内，先做小批次，再按验收结果扩展；只使用已核对且获授权的网页或客户端。失败记录为失败，不用零值替代，不静默改源、放宽 TLS 检查或绕过登录限制。
5. **核验交接**：检查响应/文件类型、实际落盘、批次覆盖与来源清单；内容检查仅在授权范围内进行。原文件保持只读；下载成功、格式验证和科学验收分开记录。

本项目没有实现上述下载器。直接使用浏览器或来源客户端不会继承 run-tool 的参数、路径与记录保护，须由人工调用方核对。

## B. 整理流程

先读[数据说明与规范化处理](../../../../methods/03_atmospheric_transport/pm25_stations.md)：明确总站发布与第三方归档的来源链、仪器/采集/代表性误差、浓度状态，以及 GB 3095 的 20 小时日均要求和文献规则的适用范围。当前示例时区/小时区间未核实时，不开始日均汇总。

1. **核对接口**：先审查来源字段和目标契约；真实任务获准后再检查实际 字段结构、缺失编码和单位。大陆、台湾、加拿大及均一化产品分别适配。
2. **规范化观测**：按来源展开站点宽列或小时字段，保留字符串站号、原时间和来源；明确筛选污染物及平均时段。保留原始质量标记，不伪造“已质控”。
3. **关联站点历史**：按显式键及有效期连接元数据，核验唯一性、迁站和坐标参考；不按列位置或城市名称永久匹配，不以最新坐标替换全部历史。
4. **处理重叠和汇总**：先定义唯一观测键、重复/冲突处理，再统计有效唯一时次。日均/年均有效性按明确标准版本、适用日期与研究目的判断，行数不能替代有效小时数。
5. **验收交接**：按[质量与交接](../../../../methods/03_atmospheric_transport/pm25_stations_preparation.md)输出长表、元数据版本、覆盖/缺失摘要和处理说明。补值、异常截断、迁站合并或均一化须另有方法与授权，不能静默改变观测。

## 人工适配与当前能力

历史资料中可复用的是宽表展开、日值汇总及坐标关联思路。旧流程包含固定路径/年份、交互式工作目录、隐式连接键与计数假设；没有证据证明它们是可直接复用的下载器。详见[适配清单](../../../../methods/03_atmospheric_transport/pm25_stations_preparation.md#人工适配清单)。

不复制旧脚本到本技能，不直接调用或注册它们。未来适配器须有显式参数/依赖、只读输入、新输出目录、失败状态、路径检查和脱敏回执；先通过合成数据与 HTTP 替身测试，再考虑单独登记工具。

## 路径、凭据与 代理 边界

遵守[统一存储约定](../../../../harness/storage-and-credentials_ZH.md)和 [代理 边界](../../../../harness/agent-boundaries_ZH.md)：

- 非秘密计划/来源映射：`AIRMOSAIC_CONFIG_DIR/pm25-stations/`。来源根由成员配置，不自动加载；公开示例不用个人绝对路径。
- 任务下载及派生产物：`AIRMOSAIC_ASSETS_DIR/results/<project_id>/<run_id>/03_atmospheric_transport/pm25-stations/`，原文件、处理结果、站点元数据和质控摘要分开；按授权发布的缓存使用 `data/03_atmospheric_transport/PM25_Stations/<source>/<version>/`。
- 运行与验收摘要：`AIRMOSAIC_ASSETS_DIR/results/<project_id>/<run_id>/records/<tool_id>/`；共享记录仅含逻辑来源、相对位置和脱敏状态，不写签名 URL 或原始认证日志。
- 如渠道需浏览器，会话位于 `AIRMOSAIC_AUTH_DIR/browser_profiles/<source>/`；密码/令牌 放秘密管理器。三根独立、位于 Git 外；目录约定不是 操作系统隔离证明。
- 远程检查只复用已授权的客户端/配置/别名组合，核验最终计算端点并限定目录；不读完整 SSH 配置、密钥或无关任务日志，不将管理节点作为处理入口。技能不包含个人连接映射。

## 完成条件

说明类任务交付来源选择、缺口及适配清单即可，不声称数据已下载或验收。获取/整理类任务分别交付其授权范围内的产物与验证证据；范围、来源、时间语义或权限无法确认时，保留待核实项，不推测结果。

数据与结果按[资产目录与复核入库规范](../../../../harness/assets_ZH.md)管理：数据按阶段、实际名称和版本共享；结果按项目及运行归集。跨阶段引用同一数据，复用入库需人工批准。
