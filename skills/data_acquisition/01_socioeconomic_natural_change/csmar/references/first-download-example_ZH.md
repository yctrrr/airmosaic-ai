2026-10-27 本人登录后，已通过外部 Chrome 验证：一家企业、一个统计截止日、八个字段，取得一个 ZIP，并验收一条有效记录。权限与存储准备见[首次使用向导](first-download-guide_ZH.md)。

## 查询与字段

打开[官方表入口](https://data.csmar.com/csmar.html#/datacenter/singletable/search?databaseId=176)，确认选中“上市公司基本信息年度表”。本例证券代码为 `600028`，起止日期均为 `2023-12-31`。日期指统计截止日期，不是下载日期或公告日期。

| 来源字段 | 含义 |
|---|---|
| `Symbol` | 股票代码 |
| `ShortName` | 股票简称 |
| `EndDate` | 统计截止日期 |
| `IndustryName` | 采用该表对应分类口径的行业名称 |
| `IndustryCode` | 对应行业代码 |
| `FullName` | 中文全称 |
| `PROVINCE` | 注册地所属省份 |
| `CITY` | 注册地所属城市 |

这些是来源字段编号，不是执行器参数。本例无需个人联系方式、管理人员及具体地址字段。

## 网页操作

1. 设置起止日期，离开输入框提交修改；表单更新后再次核对实际日期值。
2. 打开“代码选择”，搜索所需代码，等待候选出现，只选这一项并确定。核对只选一个代码，不保留“全部代码”默认范围。
3. 保留默认的三个身份与日期字段，只补充上表剩余五个字段，核对已选八项。不勾选邮件发送或保存查询方案。
4. 点击“预览数据”，确认一条匹配记录。关闭预览，等待弹窗真正消失再继续。
5. 点击“下载数据”，等待独立的下载概要页。页面准备期间不反复提交；延迟时核对同一任务或下载记录。
6. 再次核对表名、代码、日期和 XLSX 格式。“选择字段”的折叠显示只列部分字段，点击“展开”确认八个编号齐全，再用“本地保存数据”取得 ZIP。
7. 只将本任务的新文件复制到授权工作区的全新目的位置并核对副本，保留浏览器下载件；不搬移会话或其他下载。账户专用压缩包名和认证链接不进入共享资料。

## 文件验收

已验收 ZIP 为 218,974 字节，含三个成员，其中有一个 XLSX 工作簿和一份字段说明文本，归档 CRC 检查通过。工作簿有八个预期列、两行说明或单位行、一条有效企业与日期记录。字段说明与选择一致；数据匹配所需代码和日期，无重复键，已选字段无缺失。

证券代码按文本读取。按实际数据键契约区分说明或单位行与观测，不把工作簿每行都计为企业，也不对其他版本机械删除固定行数。验收归档时不把成员名解压成文件系统路径。来源文件及详细回执留在 Git 外。
