# 规划排放清单输入

[English](SKILL.md) | **中文**

本入口仅支持方法规划，没有执行工具、脚本、配置文件或数据示例。

## 使用步骤

1. 明确源类别、时期、区域、污染物与核算边界。
2. 选择来源类型及覆盖、一致性和缺失的评估方法。
3. 明确单位、类别对应及来源重叠的处理原则。
4. 规划完整性、重复计算和不确定性检查。

交接简要的方法选择记录：来源类型、预期统计覆盖、映射原则、未解决缺口及质量检查。后续据此设计核算，本入口不执行数据获取或计算。

阅读[核算设计](../../../../methods/02_emission_inventory/emission_accounting_ZH.md)与[空间分配](../../../../methods/02_emission_inventory/spatial_inventory_ZH.md)。第二步保留概念方法，不包含具体数据、参数或代码。
