# 工作流复用前的决策与检查

[English](checklist.md) | **中文**

| 步骤 | 需要确定并保留的内容 | 停止或适配的条件 |
|---|---|---|
| 计划与审核 | 生成前保存选择、理由、证据、备选、不确定性及准确审核范围 | 待审时生成实验代码；用历史设置或自动标志替代用户判断 |
| 科学问题 | 未观测的待预测时空区域、物理目标、实测或代理标签、单位及支撑尺度 | 混淆预测区域和带标签参照；把符合参照直接称为物理真值 |
| 数据 | 固定版本与哈希、字典、样本键、纳入规则和缺失情况 | 重复键、单位不兼容、无法解释的排除或输入变化 |
| 产品来源 | 变量、产品、版本，同化、融合、校准或合成生成所用观测，评估重叠及依据或未知项 | 忽略上游使用留出目标；声称下游划分已消除依赖；无依据声称独立 |
| 可获得性 | 回顾或预报用途、数据对应时间、实际发布时间及预测起点 | 使用之后才能获得的信息，却声称完成业务预报 |
| 验证设计 | 独立单位、训练/选型/最终测试成员及固定折分 | 同站点或同组跨越边界；用随机划分声称空间或未来泛化 |
| 样本规模 | 研究特定的划分数量或比例、可用独立单位，以及单独的计算上限 | 未经审查沿用演示数量；未说明的降采样改变研究队列 |
| 预处理 | 在训练边界内拟合填补、编码、筛选；需要时逐折拟合 | 已学习信息跨越训练边界；未见类别被静默更改 |
| 模型 | 候选定义、预算、基线、种子和选型指标 | 静默替换不支持的模型或调参程序 |
| 评估 | 冻结选择、共同队列、RMSE/MAE 和明确的 R² 公式 | 把选参成绩作为最终估计；根据测试结果再选候选 |
| 解释 | 对应的拟合模型、背景、单位、取值边界及近似方法 | 把另行重拟合的模型说成最终模型；把重要性当因果效应 |
| 因果问题 | 变量物理含义、对比、机制依据、备选 DAG、识别假设及敏感性 | 混淆代理量与物理量；把假设的箭头或配置标志当作证明 |
| 执行许可 | 获准计划、数据及任务不变，准确代码已查，代理审核有真实委托，测试和预检通过 | 审核过时、代码变化、缺少检查，或代理自行颁发用户授权 |
| 复用 | 提示词、代码/配置/数据身份、环境、预测、检查和复核状态 | 只凭退出码验收；私人内容进入可复用示例 |

当前适配器在训练集拟合候选、验证集选型，再对冻结选择进行测试集评估。不自动执行嵌套调参，也不生成空间或时间划分。共享复现函数支持显式折号和有界森林搜索；经审查的调用方仍需定义科学队列、预处理及留出评估。不支持的设计保留为适配项。

预测解释与因果估计使用独立分支。因果图的讨论保留在[科学方法](../../methods/shared/machine_learning_model/README_ZH.md)。图结构检查不能证明真实世界满足这些假设。

执行器不审查产品来源，也不提供独立的无标签区域推理与导出入口。需要时核对来源文档，将这些操作列为明确适配项。未知依赖会限制独立性结论，须保留在评估中。

## 外部设计依据

以下内容用于设计参考，不表示 AirMosaic 已实现这些系统或符合整套报告标准。核对日期：2026-10-28。

- [Paper2Agent](https://arxiv.org/abs/2509.06917)提供了提取可复用操作、通过可执行测试迭代的思路。其[提示词说明](https://github.com/jmiao24/Paper2Agent/blob/main/skills/paper2agent/paper2mcp/references/extensions.md)区分流程指令与实际执行。对应改进：提示词引用真实技能，结果必须有实际运行证据。
- [MLAgentBench](https://arxiv.org/abs/2310.03302)通过实验、代码执行与产物检查评估代理。对应改进：保留生成代码和执行证据，不仅评价计划文本。
- [REFORMS](https://arxiv.org/abs/2308.07832)提供机器学习科学研究的报告建议。对应改进：记录数据、模型及评估的决策和证据；合成示例不等于科学验证。
- [mlr3 手册的嵌套重抽样章节](https://mlr3book.mlr-org.com/chapters/chapter4/hyperparameter_optimization.html#sec-nested-resampling)区分调参与性能估计。对应改进：最终评估保持独立，准确说明已参与选参的交叉验证成绩；是否实施嵌套重抽样仍需明确设计。


执行时遵循[统一过程记录规范](../../harness/usage/workflow-handoff_ZH.md)：生成依据先保存到本次 gen_script/，实际调用记录 events.jsonl；回顾摘要在操作后撰写并标明类型。每次保留任务名、精细时间、时差、代码和依赖版本；总体状态及产物哈希均通过后才报告交付完成。当前示例仅采集控制器边界，不采集完整大模型或 R 内部轨迹。
