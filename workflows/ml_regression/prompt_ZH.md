# 先规划、审核，再生成回归实验

[English](prompt.md) | **中文**

把下面提示词交给宿主代理。它不调用大模型接口，也不执行 YAML。采用[规划交接](planning_ZH.md)、[科学规划方法](../../methods/shared/model_planning_ZH.md)及[技能记录契约](../../skills/model/shared/machine_learning_model/references/planning_ZH.md)。

```text
使用 AirMosaic 回归技能完成本次有边界的任务。
模式：<按要求新建 | 明确要求的复现>。
问题：<物理目标、单位、未观测时空区域、带标签参照及用途>。
输入：<已授权、固定的数据版本和字典>。
审核方式：默认人工；只有实际用户明确授权才委托代理。
预算与保存：<允许模型、时间与线程，以及新的结果范围>。

1. 阅读方法与技能，检查获授权元数据和开发集特征；
   不用最终测试目标值设计变量或参数，列出未支持操作。
2. 生成实验代码前，保存人类可读方案和机器计划。
   解释目标，逐变量的纳入或排除及物理、代理含义，产品来源与可获得性，
   参数范围及实际候选，独立划分单位和数量，预处理，选型与测试指标，
   解释及不确定性。每项给出选择、理由、证据、备选与未解决事项。
   区分科学依据、软件参数定义和工程预算。
   样本使用由数据及研究决定，不继承演示数量；历史配置仅作参考，不作为新方案默认。
3. 提交方案供人类判断，待审时停止生成实验代码。
   用户明确委托后，保存真实授权、范围和准确计划哈希，再开展并记录代理审定。
   不制造人工批准，不从自动标志推断授权；阻塞性科学问题使受影响操作停止。
4. 使用获准计划、数据和审核证据通过技能的生成检查。
   之后才生成或复用简短调用代码并形成执行任务，数值计算保留在技能模块。
   如实记录代码生成方式。因果要求先保留有依据的 DAG、对比和不确定性，
   不从重要性推导调整变量。
5. 审查准确代码和配置，完成语法、范围、合成测试、依赖及预检，
   保留技术依据与代码、计划哈希。执行前再通过执行检查：
   任务和数据须对应获准计划，准确代码须对应检查；方案改变后旧审核失效。
6. 仅在范围内执行，不安装软件、不读取凭据、不扩大数据访问。
   使用新结果，保留失败记录；核对样本键与观测，独立重算 RMSE、MAE、
   1-SSE/SST，重载模型并检查解释来源。不根据最终测试成绩修改设置。
7. 保留计划、审核、委托、提示词、代码及配置与数据身份、环境、实际事件，
   并另写明确标注的回顾摘要。科学项目使用外部 assets/results/<project_id>，
   支持的合成工作流检查保留原声明的忽略范围。不覆盖旧结果，不自动入库。
   分别汇报计算、审核状态、科学限制及所需适配。
```

[计划调用程序](examples/planned_regression.py)对支持的任务设置实施两个交接节点，在批准后复制经审查的调用程序，执行前还需代码和测试依据。[原合成程序](examples/generated_regression.py)保留作固定技术重放，不能证明新研究完成了计划审核。

遵循[统一过程记录规范](../../harness/usage/workflow-handoff_ZH.md)。结果使用12位年月日时分加公开任务名；生成代码和显式设计依据放在本批次 `gen_script/`，实际事件分别记录，回顾明确标注为运行后撰写。不补写生成会话或隐藏思考记录。
