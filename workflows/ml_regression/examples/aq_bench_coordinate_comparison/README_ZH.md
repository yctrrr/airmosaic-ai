# AQ-Bench：坐标变量配对比较方案

[English](README.md) | **中文**

状态：**待人工审核的研究方案，尚未生成实验代码或训练新模型**。本例展示如何把文献、数据契约和科学判断交接给代理；实际结果需保存在外部项目资产中。历史代码、配置和结果均保留。

本轮关注的是“变量和参数为什么这样选，代理生成的代码是否忠实落实这些选择”，不是先跑分再补写理由。[结构化方案](comparison-plan.json)、[开发信息核对](development-profile.json)、[代码审查映射](code-review_ZH.md)和[生成提示词](prompt_ZH.md)共同构成审核材料。

## 1. 问题与两种比较

目标是 `o3_average_values`，单位 ppb，样本单位为站点，代表 2010–2014 年长期臭氧汇总值；不用于逐日预测或未来预报。输入采用已登记的 [AQ-Bench v1](../../../../assets/data/03_atmospheric_transport/AQ-Bench/v1/README_ZH.md)。

| 组别 | 特征 | 拟回答的问题 |
|---|---|---|
| A：不含坐标 | 下表 V01–V08，共 8 个环境特征 | 有限环境信息能支持怎样的预测？ |
| B：加入坐标 | A 加 V09–V11，共 11 个特征 | 在相同样本、验证、参数及预算下，位置代理增加了什么？ |

A 仍包含具有空间结构的地形与地表信息；本轮比较坐标代理的增量作用，不是比较所有空间信息的有无。

**固定设置配对比较**逐一比较相同参数与种子下的 A/B；**等预算选型比较**允许两组各自在相同内层验证中选型，再比较冻结流程。后者同时包含参数选型差异，不能全归因于坐标。两者都不估计坐标的因果效应。

[Meyer 等（2019）](https://arxiv.org/abs/1908.07805)支持检查空间变量选择与地图伪影；[Milà 等（2024）](https://gmd.copernicus.org/articles/17/6007/2024/)说明空间代理的作用取决于插值或迁移、残差依赖与采样格局。下面的具体组合是本研究提出的可检验假设，并非这两篇文章推荐的固定特征表。

## 2. 逐变量依据

| 决策 | 变量及单位 | 本轮纳入理由 | 必须保留的限制 |
|---|---|---|---|
| V01 | `alt`，m | 描述海拔相关的暴露、输送与背景差异 | 不能直接等同于混合或化学过程 |
| V02 | `relative_alt`，m | 区分局部地形位置与绝对海拔 | 按来源定义使用，不当作边界层高度 |
| V03 | `water_25km`，% | 描述水面、海岸与陆地背景差异 | 不代表海风测量；25 km 是输入尺度 |
| V04 | `forest_25km`，% | 汇总森林地表背景，避免五类森林同时扩张搜索 | 丢失植被类型差异，不是 VOC 通量 |
| V05 | `grasslands_25km`，% | 与森林、耕地及建成区区分地表情境 | 不能直接推定排放或吸收速率 |
| V06 | `croplands_25km`，% | 表示农业地表背景 | 不代表施肥量、农时或农业因果效应 |
| V07 | `urban_and_built-up_25km`，% | 在前体排放以外保留建成环境信息 | 与排放可能冗余，也可能编码位置；并非必选变量 |
| V08 | `nox_emissions`，g m-2 y-1 | 纳入已有臭氧前体排放信息，避免完全依赖位置代理 | 不是环境 NOx 浓度；与臭氧关系不能预设为单调 |
| V09 | `lat`，deg | 仅在 B 中检验纬向位置代理 | 不等同于温度或辐射 |
| V10 | `lon_sin`，1 | 经度正弦编码，避免日期变更线数值跳跃 | 需与余弦成对理解，不保证空间泛化 |
| V11 | `lon_cos`，1 | 补足经度周期表达 | 不独立改变它来解释地理效应 |

定义来自公开字典；V01–V08 的机制假设参考 [AQ-Bench 数据论文](https://essd.copernicus.org/articles/13/3013/2021/)与[臭氧制图研究](https://gmd.copernicus.org/articles/15/4331/2022/)。来源支持变量的候选意义，不证明每项在本数据中必要。`comparison-plan.json` 为每项保存具体来源、理由与不确定性。

首轮不纳入其他臭氧统计量；样本键、国家、区域、类别与划分标签只作元数据。人口指标暂缓，先核对其单位、空间支撑与极值；不静默缩放或截断。NO2 柱、夜光及气候类别留待尺度、来源或类别边界审查后扩展。其余地表子类、产量及缺失的温度、辐射不自动加入。这是有意限定的环境集合，不能代表完整的大气过程。

## 3. 预处理为什么这样做

1. 原始 v1 只读，保留 `id`，获准后另建准备版本。训练、验证和各组记录均按键对齐。
2. 将已声明缺失标记转为缺失，不制造目标值。两组共用目标有效性与质量排除清单，不能各自删除不同样本。
3. `forest_25km` 只在五个原始森林分量齐全时求和；任何分量缺失则总量缺失，不填成零。五列名称在结构化方案中逐一列出。
4. `lon_sin = sin(lon*pi/180)`，`lon_cos = cos(lon*pi/180)`，纬度保留原符号。这些是不学习数据分布的确定性变换，但仍需代码和单位测试。
5. 不标准化、不裁剪、不缩尾、不变换目标。树模型不要求标准化；有效负海拔与零覆盖比例保留。越界比例、坐标或负排放触发来源复核，不能自动修正。
6. 主比较手动声明特征，不用相关性或 VIF 自动删列，避免两组悄悄变成不同环境集合。必要的中位数只在当前拟合训练子集估计，不能从外层评估样本计算。

本轮只读取训练特征及键、划分、区域和位置元数据，未用目标数值制定方案。原训练集 3,348 行中，上述环境分量与坐标未检出缺失。坐标与本轮环境特征的最大绝对 Pearson 相关约 0.351；这既不能证明空间安全，也不支持把“高线性相关”当作本数据已确认事实。

## 4. 参数范围与实际比较点

[Probst 等（2019）](https://arxiv.org/abs/1804.03515)提供参数机制；[树数研究](https://jmlr.org/papers/v18/17-269.html)讨论集成稳定性；准确语义按 [ranger 手册](https://imbs-hl.github.io/ranger/reference/ranger.html)。**下列数值仍是待检验的本轮方案，不称为文献最优值。**

| 决策 | 实际拟定值 | 选择依据及限制 |
|---|---|---|
| H01 | `mtry = 3, 6` | 3 接近 8 或 11 个特征的平方根；6 检验更强特征竞争。两组保持相同绝对值，因此相对比例不同，不能声称分裂入选概率相同 |
| H02 | `min.node.size = 5, 25` | 5 是常见回归参照；25 是本研究提出的五倍粗化分裂要求，用于比较噪声与局部拟合。它不是已验证最优值，也不是叶节点最小样本数 |
| H03 | `num.trees = 500` | 作为计算可承受的常规起点，显式设置以免落入执行器省略时的 100 棵回退。250/500/1000 的开发集稳定性诊断另列，尚未执行 |
| H04 | `sample.fraction = 0.632`、`replace = false` | 采用常见无放回抽样参照，并固定抽样以限制首轮搜索维度；不代表按组抽样或该比例最优 |
| H05 | 不填写 `max.depth` | 按 ranger 默认不限深度，避免继承历史固定深度。节点阈值为主要复杂度比较轴；不限深度仍可能过拟合 |
| H06 | 模型基种子 4101/4201/4301；抽样 8101；解释 9101 | 只用于重复与配对。两组保持模型顺序一致，并记录执行器派生后的有效种子 |
| H07 | 内层汇总 RMSE 选型，报告 MAE、偏差与 `1-SSE/SST` | RMSE 对大误差惩罚更强；MAE 补充典型误差。按 MAE 选型不会改变森林内部的方差训练目标 |
| H08 | 解释背景/验证各 100，置换 5 次，响应网格 9 点 | 仅为次级诊断预算，不表示解释已收敛；PDP/ICE 只请求共同的海拔和 NOx 字段 |

核心网格为四种组合：`rf_m3_n5`、`rf_m3_n25`、`rf_m6_n5`、`rf_m6_n25`，另有训练均值基线。每个组合在 A/B 中保持顺序、折分和种子一致；相同种子不保证特征数变化后每棵树抽到相同记录。500 棵的稳定性未被证明，若开发诊断显示不稳，应在外层评分前修订方案。

当前解释草案只请求共同的海拔与 NOx，不生成坐标组重要性。经纬度组的联合置换仍需技能适配，不能从现有单变量输出判断整个坐标组的贡献。

[不含坐标任务草案](task-no-coordinates.draft.json)与[加入坐标任务草案](task-with-coordinates.draft.json)符合现有任务结构，**仅表达原划分比较的设置**。尚缺准备输入，不能直接拿原 CSV 执行；它们不实现空间验证，也不是已有批准。

## 5. 空间验证怎么设计

### 原划分：兼容性配对比较

保留来源训练/验证/测试成员，数量为 3,348/1,114/1,115；它们是此数据版本的实际数量，不是通用划分规则。草案将计算上限设为来源数量，准备后仍须报告实际可用数量。

原方案已经按空间聚集划分，不能叫作普通随机按行拆分。不过本轮大圆距离核对发现，验证与测试分别有 475、424 个站点距训练站不足 50 km。因此不能把原协议解释成处处满足 50 km 隔离。此前测试分数已经查看，本轮只能做透明的基准再分析，不能宣称新的未接触测试。

### 空间迁移：待实现的主要敏感性检验

1. 使用原训练加验证的 4,462 个站点作开发池，原 test 不进入该池。依次完整留出 NAM、EUR、EAS：评估元数据数量为 1,306、1,749、1,240；其余区域共 167 个站点只参与拟合，不冒充其外推已获验证。
2. 外层拟合侧删除距该次留出站点不足 50 km 的记录。仅依据元数据，预计保留 3,143、2,711、3,221 行；最终数量还取决于获准的目标有效性与质量检查。
3. 每次外层拟合池内设三个空间验证折：EPSG:6933 等面积坐标、250 km 网格、原点 `(0,0)`，同一格不拆分。按格内样本量从大到小、同量按格键排序，依次分配至当前最小折，不按目标平衡；每折再删除距验证站不足 50 km 的训练记录。
4. 所有插补和学习型操作均只在各拟合折执行。汇总相同验证站点、三个模型种子的折外平方误差选型；精确同分按预先模型顺序处理。外层评分不参与选型。
5. 冻结选择后，重新拟合每项预定固定设置及内层选定流程，使用全部合格的外层训练记录，不把某个内层模型当成最终重拟合。外层标签仅用于冻结后的评分。
6. 分别报告区域误差、同设置 A/B 差值、各自选型后的差值与种子波动。汇总 RMSE 从站点误差重算，不将各折 RMSE 的平均当成汇总 RMSE。

250 km 格网、50 km 缓冲和三个折是**需审核的设计起点**，不是文献证明的独立性尺度。先检查格数、各折规模、最近训练距离及支持范围；不满足条件时返回修订，不能看过模型分数后降低距离。[Roberts 等（2017）](https://doi.org/10.1111/ecog.02881)也提醒，分块可能改变插值或外推的评估问题。

核心设计约含 216 次内层森林拟合、72 次外层固定设置重拟合，合计 288 次，不含均值基线与另行限定的稳定性扩展；本轮一次也未启动。三个区域留出不构成全球置信区间；已有探索过的基准重抽样，也不是全新外部验证。

没有区域预测网格与部署距离分布，因此暂不声称完成地图精度、kNNDM 或适用域验收。站点评分本身不能显示地图是否出现块状边界。

## 6. 如何观察代理生成代码的依据

先看[代码审查映射](code-review_ZH.md)，再看[提示词](prompt_ZH.md)。审核后，生成材料必须能把 `V01–V11`、`P01–P07` 和 `H01–H08` 对应到实际特征、参数、预处理、折分及代码位置；不能只附论文列表或事后重要性排名。

现有 `planned_regression.py` 复制获准调用代码与任务，不会自行科学选变量，也不支持上述嵌套空间过程。准备、折分、开发阶段拟合与外层重拟合应作为可复用技能实现；workflow 保留编排及逐项依据。当前只交付计划、任务草案与审核要求，没有伪装成已生成的模型代码。

生成前需要审核变量与聚合、参数起点、迁移问题及空间尺度。真实数据结果未来使用外部 `assets/results/<project_id>/` 下的新目录，目录内部按任务决定，`gen_script/` 与该次结果一起保存；本工作流的本地结果目录仍只允许合成检查。
