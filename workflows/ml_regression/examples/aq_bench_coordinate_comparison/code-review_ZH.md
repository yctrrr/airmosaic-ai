## 当前代码实际做什么

[已有调用器](../planned_regression.py)在审核通过后，将 `plan["task"]` 写入 `gen_script/task.json`，再复制经审查的调用程序；运行时经技能审核助手和执行器调用 `ml_regression_workflow`。它不根据文献自主选变量或参数，也不生成新的数值算法。`generation.json` 中的复制模式应如实保留。

[准备模块](../../../../skills/model/shared/machine_learning_model/scripts/r/common/prepare.R)读取配置中的列、缺失策略及现有划分；[变量模块](../../../../skills/model/shared/machine_learning_model/scripts/r/common/select.R)按所选策略诊断或过滤；[拟合模块](../../../../skills/model/shared/machine_learning_model/scripts/r/models/fit.R)训练列出的候选并以验证误差选择。它们不读取论文来判断科学合理性。

因此，代码里出现一个参数值，不等于已有科学依据；只有它能对应到获准计划、实际配置与执行值，才能审查该选择是否被忠实落实。

## 逐项对应表

| 依据编号 | 配置或数据对应 | 生成后应检查什么 |
|---|---|---|
| V01–V08 | A/B 的 `features` 前八项 | 环境集合及顺序完全一致，不被重要性或相关性规则偷偷修改 |
| V09–V11 | 只有 B 增加 `lat`、`lon_sin`、`lon_cos` | A 的元数据仍有位置，但特征中不包含坐标；B 的经度周期变换准确 |
| P01–P04 | 准备数据、`id` 与衍生列 | 原始输入哈希不变；五项森林合成和角度变换可重算；两组键一致 |
| P05–P07 | `missing`、`feature_selection` 与逐折拟合 | 未裁剪或填补目标；中位数只来自当前训练折；没有默认相关性过滤 |
| H01–H02 | `models[*].parameters` | 四个 `mtry` 与节点阈值组合准确；B 不额外获得更多搜索机会 |
| H03–H05 | 树数、抽样、未填写参数 | 显式 500 棵、无放回 0.632；记录不限深度及方差分裂的实现默认，不能只记录显式字段 |
| H06 | `seeds`、候选顺序与拟合记录 | 同一设置在两组使用相同派生种子；记录折身份、基础种子和有效种子 |
| H07 | 内层比较、外层评分 | 外层标签及分数不进入选型；按站点误差重算汇总指标 |
| H08 | `explanation` | 共同背景抽样与解释预算可追溯；不单独改变经度正余弦来做地理 PDP |
| 空间协议 | 折清单、距离与重拟合记录 | 不拆网格；缓冲在拟合侧执行；选择后重拟合全部合格训练记录，不能拿内层模型替代 |

每项需保留：`decision_id`、`source_id`、`study_reason`、`alternative`、`uncertainty`、`config_field`、`code_location`、`effective_value`、`check_evidence`。这些是要求生成后补齐的实际证据，不是本轮已经捕获的记录。

## 生成顺序与待适配能力

`comparison-plan.json` 是多组科学设计草案，不符合单任务 `model-plan.schema.json`，不能直接交给审核器冒充可执行计划。两个任务草案只用于展示原划分字段，尚无准备输入。

获准后先设计可复用技能接口：确定性准备、配对队列、空间分组与缓冲、只面向开发集的拟合，以及冻结后的外层重拟合和评分。现有执行器要求训练/验证/测试三份标签，并自动评估所选模型；不能给内层调用传入外层测试标签，再把重复测试评分称为隔离。

workflow 的后续调用代码只编排这些技能接口，保存任务与决策对应，不将关键数值计算搬到 workflow。准备、折分和接口先经合成输入验证，再把真实准备数据哈希、明确任务及审核材料绑定为各次技能计划，经过准确代码检查后才执行。

生成后的数据流应能逐步核对：

`comparison-plan.json` → 实际获准计划 → 已绑定准备输入与折清单 → `gen_script/task.json` + `run.py` → 技能准备/拟合/评估 → 结果核验

这是待实现流程，不是新的命令入口或已完成运行。

## 结果中需要回答的问题

- 同一参数下，坐标效应是否随地区、种子变化？不同最优参数的流程比较是否被单独标注？
- 所谓改善是否仅出现在近距离基准划分，在区域留出中消失或反转？
- 变量组、样本量、有效种子或默认设置是否发生了未说明变化？
- 生成前依据、实际动作与事后回顾是否分开标注？未实现、跳过和失败是否如实记录？

没有区域特征网格时，只能讨论站点预测与空间依赖诊断，不能从分数推断地图没有块状伪影。
