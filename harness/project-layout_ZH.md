阶段提案保留历史候选方法供参考，不作为自动选型规则、可执行定义或已经验证的科学默认值。新增可执行路径应放在 `core/workflows/<pathway_id>/`，对应的方法叙述放在 `methods/pathways/`。[核心工作流状态](../core/workflows/README_ZH.md)说明未实现部分。

## 安装

在仓库根目录：

```sh
python -m pip install -e './core[dev]'
python -m airmosaic_core.cli list-tools
python -m pytest core/tests -q -p no:cacheprovider
```

在 `core/` 中使用 `python -m pip install -e '.[dev]'` 和 `python -m pytest tests -q -p no:cacheprovider`。旧环境迁移后需要重新进行可编辑安装，不向 Python 路径注入原源码目录。目录与专业脚本资源仍依赖完整源码检出，独立发行尚未实现。

## 一份定义，多个入口

`catalog/tools/*.yaml` 仍是唯一工具注册来源，执行器继续核对已审查的适配器策略。命令行与未来 MCP 入口必须共用注册和执行服务。MCP 负责通信及调用，不维护第二套目录。方法链接、技能安装和工作流文件均不授予执行权限。

数据声明仍由技能原有 `datasets.yaml` 加载，`catalog/datasets/` 保持当前详情回退用途。本次不归并两者、不改变数据集编号；后续归并需要单独实现并检查兼容性。

## 范围与边界

本次改变位置、安装与引用，保留工具编号、适配器支持和科学计算代码。MCP、编排、产物登记与通用科学校验仍未实现，不为这些能力创建伪可执行入口。

四个研究步骤继续组织内容，跨阶段能力保持共享。第二步仅列概念方法。个人数据结果、非秘密设置及认证分别保留在 Git 外的三个独立根目录。迁移检查不需要原始数据或凭据。历史私人草案和无关改动不纳入提交。

英文使用默认文件名，中文使用 `_ZH.md`，两版同步更新。历史长篇参考保留现有语言。遵循[编写清单](skill-authoring_ZH.md)与[存储约定](storage-and-credentials_ZH.md)。

## 迁移验证——2026-10-27

在 Windows、Python 3.12 下，原有 144 项测试和新增的 3 项已安装命令检查通过。新增检查分别从仓库根、`core/` 和外部临时目录查询能力。保留两条既有源码解析警告，安装使用迁移后的可编辑项目。

25 个工具声明的编号和行为保持不变，仅 9 个核心入口路径改变。16 个专业计算源码及全部 15 个公共运行源码与迁移前逐字节一致。结构文件解析、双语命令和语言切换、路径及映射一致性和共享文件隐私扫描通过。检查仅使用公开代码与合成输入，没有读取原始数据或凭据，也未进行真实获取或模型任务。
