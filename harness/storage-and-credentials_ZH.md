# 数据工作区、个人配置与凭据

<!-- README-I18N:START -->

[English](storage-and-credentials.md) | **中文**

<!-- README-I18N:END -->


共享代码和规范，分别管理成员的数据、真实路径与认证。具体能力的映射放在技能及分类用法中，不写入通用存储规则。

## 1. 存储职责

| 位置 | 内容 | 边界 |
|---|---|---|
| 仓库 | 可复用代码、文档、结构定义和公开示例 | 不存真实数据、秘密或个人映射 |
| `AIRMOSAIC_LOCAL_WORKSPACE` | 缓存、新结果、本地记录和临时文件 | 不存认证和凭据 |
| `AIRMOSAIC_CONFIG_DIR` | 非秘密映射及偏好 | 明确审核后加载，不含秘密 |
| `AIRMOSAIC_AUTH_DIR` | 必须落盘的本人浏览器状态 | 限制访问，不存数据和共享结果 |
| 外部资源根 | 已授权发行包及既有外部资源 | 单独配置的只读输入，不自动授权修改 |

个人根目录已存在、相互独立且在仓库外。共享输入可只读，但可写任务按成员划分。仓库中的 `config/examples/` 不等于个人配置。设置变量不启动浏览器、不登录、不加载配置，也不授权修改。`.env` 不自动加载。

工作区使用 `data_cache/<source>/`、`output/<run_id>/<tool>/`、`runs/<run_id>/`、`temp/<run_id>/`。认证根下的会话使用 `browser_profiles/<service>/`。这些是逻辑示例，不是私人路径。

## 2. 配置与日常使用

1. 检查仓库与现有目录，不替换数据或设置。
2. 审查[环境示例](../config/examples/README.md)，复制到仓库外并显式加载已核对的会话设置。
3. 三根不重叠、不嵌套，且位于所有仓库副本外；数据根不能成为认证根的父目录。
4. 每次任务分配唯一编号，按真实输出参数映射新目录。配置文件名不授予权限。
5. 需要登录时由本人完成，只返回就绪、需认证或无权限等脱敏状态，不回传凭据。尚无统一认证适配器。
6. 授权共享前检查差异、日志和附件。完整本地记录可保留必要路径，但不能含认证秘密。

认证目录按操作系统权限限制至本人，不向所有成员开放。目录权限与秘密存储分别管理；相同系统身份的代理通常拥有相同文件访问能力。

## 3. 凭据管理

| 材料 | 保存与使用 | 维护 |
|---|---|---|
| 仓库访问 | 已审查的凭据助手或个人私钥存储 | 本人登录，按设备用途区分，只分享公钥 |
| 网站密码与多因素验证 | 本人秘密管理器与交互式登录 | 不让代理收集密码、恢复码或批量尝试 |
| 浏览器认证 | 认证根下按成员和服务独立的配置 | 账号变化或过期后重新登录，不复制会话 |
| 接口凭据 | 系统或团队秘密存储，运行时按需注入 | 限定权限、用途和有效期，有权限者轮换 |
| 自动化秘密 | 平台保护的秘密存储及合适身份 | 最小授权，不上传个人会话 |

环境变量是传递方式，不是加密存储。秘密不得写入命令、示例、代理说明、快照或日志，不新增明文秘密模板或带密码的普通配置。

本人已配置的受保护秘密文件，仅可由明确授权的可信客户端在本次任务内部复用。代理不打开、解析、打印、复制、迁移、修改或哈希内容，不公开路径或指纹。文件保留在客户端既有保护位置，不是普通个人配置。不扩展到其他客户端或扫描其他凭据，秘密管理器仍优先。

专用浏览器仅访问任务相关站点，不复用含无关个人账号的日常配置。调试端点仅限授权本机，不对外开放。进程退出不证明会话已销毁。另见[行为边界](agent-boundaries_ZH.md)。

## 4. 按能力映射的通用规则

输入来自授权缓存或只读来源，新下载放任务原文件目录，处理结果与质量摘要分开。缓存发布另行授权。参数放个人配置，浏览器状态放认证根。具体旗标、资源和加载器由技能说明，模板执行前必须检查并适配。

不能假设加载模板没有副作用：它可能重置设置或写回输入树。新任务显式指定输出。直接脚本不自动继承路径检查、启动隔离或脱敏记录。

## 5. 旧目录与交接

- 不自动迁移或删除已有输出、日志、临时目录或会话，旧任务沿用原路径。
- 新任务不再混放秘密和会话，但不能通过复制会话迁移；本人可关闭旧浏览器后重新登录，空占位目录不必删除。
- 数据备份只含获准的数据和结果，认证不进入归档、问题、审查、网盘或跨成员同步。秘密备份使用单独加密方案。
- 忽略规则不加密、不限制访问，也不保护已跟踪内容。疑似泄漏只报位置与类别，撤销与历史修改需具体授权。
- 只读查询检查声明路径的元数据，不读秘密。受支持适配器提供路径预检、最小环境与脱敏记录，不把整个个人配置或认证根传给子进程。已有会话工具需核对本任务归属，凭据代理和操作系统沙箱尚未实现。
