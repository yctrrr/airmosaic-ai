# 项目结果与资产审核

[English](assets.md) | **中文**

实验结果归属对应的 `projects/` 项目。人类科学审核决定是否将选定成果纳入 `assets/`。本轮只明确这一关系，`assets/` 内部的目录、分类及数据组织方式留待后续确定，不移动或删除现有资产。

## 项目结果归属

项目结果约定为 `projects/<number_topic>/results/`，内部布局由任务选择，实际代码、配置、输入引用、结果、评价及审核依据保存在对应项目中。私人项目目录留在 Git 外；仓库中的本地项目结果目录被 Git 忽略。忽略规则不赋予执行器写入权限，也不保护已经被 Git 跟踪的文件。

当前适配器仍写入已有的外部项目结果位置，尚未实现新的项目目录写入支持。已有示例描述的是兼容接口，不代表其中的结果已作为资产获准复用。历史结果保留原位，不绕过路径检查。见[项目说明](../projects/README_ZH.md)、[存储约定](storage-and-credentials_ZH.md)与[执行接口](usage/run-tool.md)。

## 人类审核与复用

1. **在项目中计算与评价：** 保存实验、实际代码和配置、输入引用及产物清单；需要用于判断的失败尝试也予以保留。
2. **由人类作出科学判断：** 决定修订实验、仅在项目中保留结果、发布报告，或将选定成果纳入 `assets/`。程序成功和待审核模板都不表示批准。
3. **按审核决定处理：** 保留项目原件、审核依据和获准用途，公开发布单独审核。不自动复制整个项目，不将所有产物直接入库，也不根据物理存放位置推定已获准复用。

报告与审核记录留在项目中；可复用的处理过程经审核后再反馈给工作流、方法和技能。尚无自动科学审批、入库或旧结果迁移服务。个人路径、配置、认证及凭据继续分离，不随产物公开。

## 已有公开示例

仓库已有示例继续遵守其清单、许可与只读输入要求。本轮不重新设计这些声明，也不授权新增数据访问。下述通用演示及合成工作流例外保留各自已实现的边界，不据此推定任意源码目录已支持写入项目结果。

## 工作流合成检查

已审查的回归适配器额外支持显式 `result_scope=workflow`（CLI 为 `--result-scope workflow`）。仅允许清单登记且哈希一致的仓库合成 CSV，输出固定在被 Git 忽略的 `workflows/ml_regression/results/<timestamp>_<task>/`，记录和临时文件位于该结果根的 `.airmosaic/<run_id>/`。拒绝项目编号、真实或外部数据、越界目录及嵌套仓库；不改变 `auto` 的默认行为。正式研究仍使用外部项目结果根。工作流中经审查的编排示例可供复用；本次生成代码与依据放对应结果的 `gen_script/`，具体过程记录见统一交接规范。该检查不提供科学批准，也不构成操作系统沙箱。

## 工作流时间目录与生成代码

经审查的回归控制器为新结果目录使用 `<YYYYMMDDHHmm>_<task-name>`。任务名为可公开的小写标识，目录时间精确到分钟；同一分钟内同名任务仍通过排他创建拒绝覆盖。示例显式默认时差为 `+08:00`，可用 `--utc-offset` 调整；直接执行器的工作流输出使用 UTC 和任务名 `ml_regression`。每次运行保留时差信息。内部十六进制编号仅用于关联回执，不作为可见目录名。已有名称及结果默认保持原样，仅按明确授权执行有边界的清理。

每次运行的 `gen_script/` 保存实际编排代码、任务、提示词/具体请求副本及中英文生成依据。复用依赖通过 Git 基准和哈希标识，选定公共代码的改动与新增内容保存在文本补丁中；重建需人工审查，并核对所记录的标准换行哈希。仅有哈希不能恢复丢失代码。数据继续引用已登记资产版本；新运行不创建完整 `source_snapshot/`，也不复制数据。在同一源码仓库、依赖身份匹配时，可以运行保存的 `gen_script/run.py`，产生全新的结果目录。

实际 `events.jsonl`、成对的 `retrospective*.md`、独立执行器回执和 `workflow.json` 与科学产物保存在同一批次。回顾摘要明确在事后整理；事件仅覆盖控制器操作边界。`workflow.json` 是总体终态依据，需同时核对 `delivery-sha256.json` 才能视为完整交付。失败尝试及部分文件保留在本地检查，不统一强制科学产物的文件名。

仅合成工作流检查使用经审查、被 Git 忽略的工作流本地结果根；科学研究继续使用外部项目结果，个人映射与凭据保持分离。经审查后将通用操作整理为技能，仅在获准后发布脱敏可复用示例。
