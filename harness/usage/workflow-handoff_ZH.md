# 研究步骤交接与可追溯性

<!-- README-I18N:START -->

[English](workflow-handoff.md) | **中文**

<!-- README-I18N:END -->

本指南定义人工交接检查，没有工作流执行器或强制运行时契约。固定样本量、相关系数或单项测试不能作为通用科学验收门槛。原件和私人日志保留在授权本地。

| 交接 | 需要说明 | 接收条件 |
|---|---|---|
| 01 → 02 | 活动、资源、技术的定义、单位、分类、覆盖和来源类别 | 核算边界和方法语义明确；第二步仅列方法，不附具体数据或代码 |
| 01 → 03/04 | 背景及成分资料的产品、变量、时间、网格、单位和版本 | 区分观测、再分析和预报，转换及匹配另行验证，不强制经过第二步 |
| 02 → 03 | 分配与映射方法、守恒及缺口 | 按任务定义输入兼容性，目录存在不代表已经生成输入 |
| 03 → 04 | 浓度单位、网格、地表定义、平均口径、有效范围和验证摘要 | 按受体核对输入与响应指标，观测验证标准按任务制定 |
| 共享 → 各步 | 适用性、版本、边界和比较设计 | 引用同一技能，不引入排放具体实现，不把方法参考当可执行工具 |

## 记录与比较

区分方法选择、工程运行和科学验收。明确基准与干预情景、允许变化的条件和共同有效范围；来源可追溯不能单独证明因果识别。单独列出缺失项和未运行检查。

已支持工具在 `${AIRMOSAIC_LOCAL_WORKSPACE}/runs/<run_id>/record.json` 记录允许的脱敏元数据；它不是完整跨阶段来源链或科学校验服务。未适配流程不自动获得执行器保护。参见[路径说明](../../methods/pathways/README_ZH.md)、[编排实现状态](../../core/workflows/README_ZH.md)、[四步流程](../four-step-workflow.md)和[单工具执行](run-tool.md)。
