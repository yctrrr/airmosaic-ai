# 研究步骤交接与可追溯性

[English](workflow-handoff.md) | **中文**

<!-- README-I18N:END -->

本指南定义交接与执行记录要求，具体实现范围由各适配器声明，不提供通用工作流执行器。固定样本量、相关系数或单项测试不能作为通用科学验收门槛。原件和私人日志保留在授权本地。

| 交接 | 需要说明 | 接收条件 |
|---|---|---|
| 01 → 02 | 活动、资源、技术的定义、单位、分类、覆盖和来源类别 | 核算边界、单位和方法语义明确；仅已声明的合成清单路径提供经审查计算示例，不代表真实数据或执行器授权 |
| 01 → 03/04 | 背景及成分资料的产品、变量、时间、网格、单位和版本 | 区分观测、再分析和预报，转换及匹配另行验证，不强制经过第二步 |
| 02 → 03 | 分配与映射方法、守恒及缺口 | 按任务定义输入兼容性，目录存在不代表已经生成输入 |
| 03 → 04 | 浓度单位、网格、地表定义、平均口径、有效范围和验证摘要 | 按受体核对输入与响应指标，观测验证标准按任务制定 |
| 共享 → 各步 | 适用性、版本、边界和比较设计 | 引用同一技能，不引入排放具体实现，不把方法参考当可执行工具 |

## 记录与比较

区分方法选择、工程运行和科学验收。明确基准与干预情景、允许变化的条件和共同有效范围；来源可追溯不能单独证明因果识别。单独列出缺失项和未运行检查。

已支持工具按各自适配器契约保存脱敏回执；旧适配器使用项目下的阶段/工具布局，灵活结果适配器使用独立的 `.airmosaic/<run_id>/record.json`；它不是完整跨阶段来源链或科学校验服务。未适配流程不自动获得执行器保护。参见[科学设计](../../methods/shared/requirements_driven_model_building_ZH.md)、[数据与技能组合](../../workflows/README_ZH.md)、[四步流程](../four-step-workflow.md)和[单工具执行](run-tool.md)。

## 代理执行循环与过程记录

以下是工作流共同遵循的操作要求。具体适配器需要说明已经实现的部分；写入规范不代表已经具备执行引擎或完整轨迹采集。

1. 行动前，用简短决策摘要说明当前目标、证据、拟执行操作及授权和资源边界，明确假设及尚未核实的说法。
2. 行动后，根据实际工具返回及产物引用更新状态。区分计划、尝试、进程完成、数值检查与科学验收，不编造观察或倒填事件时间。
3. 在声明的开发设计和预算内调整，保留修改过的代码与配置版本。冻结最终评估边界，不根据最终测试反馈重新挑选候选。
4. 分开保存设计/生成依据、实际执行事件和运行后回顾。回顾性摘要明确标注类型及撰写时间。决策摘要是对外可检查的解释证据，不声称采集模型内部隐藏推理。
5. 遇到缺少授权、契约不兼容、冻结输入变化、必要检查失败、预算耗尽或目标冲突时，停止受影响分支。保留部分产物，汇报缺口，并按要求进行科学复核。

| 记录 | 必须表达的含义 | 保存时点 |
|---|---|---|
| 生成依据 | 具体要求、代码/配置身份、支持的选择、假设及缺失的生成元数据 | 计算前保存；说明哪些摘要是在代码生成后整理的 |
| 执行事件 | 顺序时间、控制器/动作身份、实际状态及有界证据引用或数量 | 操作发生时采集；注明延后写盘的缓冲事件 |
| 回顾性摘要 | 已完成或失败的范围、有证据的结论、局限及下一步检查 | 在实际操作后整理，不冒充当时轨迹 |

使用获准的非秘密引用、固定状态/错误类别和最少必要摘要。共享记录不包含私人路径、身份、凭据、原始模型/工具响应或无关文件。本规范不要求保留完整原始对话轨迹。

当前经审查的示例控制器记录控制器的预检、生成材料保存、技能调用及独立核验，并保存成对的生成依据和回顾说明、实际事件及封存后的总体终态回执。运行时重放已审查的生成代码，不发起新的大模型调用；历史生成所用模型和设置仍不可得。不自动采集 R 内部完整操作、宿主代理会话或完整大模型生成/修改轨迹。其他工作流沿用各自说明中的能力范围。

存储和时间目录命名见[资产规范](../assets_ZH.md)，可执行任务示例见对应工作流及技能。ReAct 提供交互范式，授权、科学控制与证据契约由本项目实现。参考：[ReAct 第 2 节](https://arxiv.org/html/2210.03629v3)、[MLAgentBench 第 2.3 和 3.1 节](https://arxiv.org/html/2310.03302v2)。
