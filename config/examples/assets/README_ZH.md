# 项目与资产模板

[English](README.md) | **中文**

只将选定模板复制到已审查的私人位置。示例只含合成标签，不含真实数据；这些是说明模板，尚不自动加载，也不是可执行工具参数。

- [项目](project.example.json)：输入引用、任务要求和项目验收条件，实际副本保存在 CONFIG_DIR。
- [资产](asset.example.json)：实际数据名称、固定版本、主要及适用阶段、工作区相对路径、数据类型与来源，完成的元数据保存在已登记数据旁。
- [复核](review.example.json)：待确认的文件、检查与人工决定，完成的记录随原结果保存。仅在另有授权的复核中填入哈希和批准；模板不代表批准。

实际工具执行使用 [run-tool 参数](../run-tool)及明确的项目、阶段上下文。引用路径经过执行器检查；模板中的资产编号目前不自动解析。[资产规范](../../../harness/assets_ZH.md)规定三步流程和旧布局兼容。
