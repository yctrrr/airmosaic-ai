# 计量经济学：问题、识别与估计

<!-- README-I18N:START -->

[English](README.md) | **中文**

<!-- README-I18N:END -->

计量经济学把经济或环境问题与数据中的可观察变化连接起来。回归系数是在特定统计模型下得到的估计；因果解释还需要可信的研究设计及假设。拟合优度、显著性和大量控制变量本身不能完成识别。先明确观察单位与目标总体、结果变量、暴露或政策、时间范围，以及要估计的**目标量**（estimand），再判断任务是描述、预测、因果效应还是结构参数。

## 建模哲学和基本架构

1. **问题与目标量。** 写清目标总体、干预或比较、结果、时间范围、单位及尺度。条件相关、预测、平均处理效应（ATE）、处理组平均效应（ATT），以及断点附近或工具变量服从者的局部效应，是不同问题。
2. **数据生成场景。** 明确观察单位、抽样范围、面板 ID 和时间；检查缺失、测量误差、样本选择、发生时序及可能的外溢。若要作因果解释，绘制因果图或明确说明混杂路径。
3. **识别。** 说明哪些变化使目标量有可能与混杂、反向作用和共同冲击区分，并列出把观测数据连接到目标量的假设。[Lewbel 对识别概念的综述](https://www.aeaweb.org/articles?id=10.1257/jel.20181361)区分因果、简约式和结构识别。
4. **模型设定与估计。** 拟合前写出方程、变量、变换、固定效应、权重和样本限制，检查数据支持与设计矩阵秩。结构模型还要明确行为方程及均衡或动态限制，用数据估计或校准参数；这些限制须与简约式效应分开论证。
5. **推断与解释。** 按处理分配和抽样机制选择不确定性估计，例如对共享冲击或处理的单位聚类。报告系数单位、不确定性、样本、识别假设、诊断、敏感性、异质性和外推边界。不能只根据最小 p 值或最大 R² 选因果叙事。

## 常用模型类别

| 类别 | 典型用途和方程 | 关键识别或有效性问题 |
|---|---|---|
| OLS / 广义线性模型 | 条件相关的基线模型 `Y = α + Xβ + ε`；二元或计数结果可选相应连接函数。 | 对所声称效应，自变量是否外生？结果模型是否合适？没有额外设计假设时，OLS 只作描述。 |
| 面板固定效应 | `Y_it = α_i + λ_t + βD_it + X_itγ + ε_it` 去除不随时间变化的个体项和共同时间项。 | 是否处理时变混杂、预期行为和政策时点？固定效应本身不证明因果性。 |
| 双重差分 / 事件研究 | 对照处理组与比较组结果的变化。 | 未处理反事实趋势与比较组是否可信，是否有预期效应？前趋势图是诊断，不是证明。分批实施且效应异质时，应按设计选择目标量与估计器，不能自动套双向固定效应系数。 |
| 工具变量 / 2SLS | 用工具 `Z` 取得内生处理 `D` 的外生变化。 | 相关性、排除限制和独立性需要实质论证；检查弱识别敏感性。额外假设下 IV 可能识别局部效应。 |
| 回归断点 | 比较分配阈值附近的观察。 | 阈值附近潜在结果是否连续，是否存在精确操纵？检查带宽和设定敏感性；效应具有局部性。 |
| 时间序列 / 预测 | 用滞后项、动态结构和验证窗口预测或描述时间依赖。 | 是否检查平稳性、结构突变、信息泄漏和样本外性能？预测成功不等于政策因果效应。 |
| 结构计量 | 在效用、生产技术、市场或动态限制下估计行为。 | 哪些参数与反事实由数据识别，哪些来自函数形式或校准？拟合和敏感性如何？ |

环境领域可将实测或清单排放、家庭支出、污染暴露等作为结果。需对齐政策时点、行业和地区标识、污染物单位与地理尺度；注明结果来自观测、清单还是模型模拟。若使用 IO、LCA 或大气模型的衍生输出作为变量，应传播其不确定性，不能把联合估计称为直接观测。[IO](../io/README_ZH.md)和 [CGE](../cge/README_ZH.md)分别提供核算或均衡情景；计量识别依靠观测中的变化。组合研究须明确变量映射和不确定性处理。

## 操作入口与公开技能参照

[计量技能](../../../../skills/model/01_socioeconomic_natural_change/econometric-analysis/SKILL_ZH.md)提供小型横截面 OLS 计算脚本和研究设计检查顺序；未实现 DiD、IV、RDD、固定效应或结构模型。这些方法需先明确研究设计，再选用审阅过的专门实现，例如部分 R 面板分析可用 [fixest](https://lrberge.github.io/fixest/reference/feols.html)，并依据其[标准误说明](https://lrberge.github.io/fixest/articles/standard_errors.html)选择推断方式。

组织方式参考了两个公开发布的 agent skills：[EconAgentSkills](https://github.com/JonasWeinert/EconAgentSkills)将数据规范、计量方法和可复现报告分开；[econometrics-skill](https://github.com/xiaomihu1992/econometrics-skill/blob/main/SKILL.md)先厘清结果、处理、混杂和识别变化。它们是工作流参照，并非将其代码或每项估计器默认值直接搬入本库；使用前仍需审阅其实现局限。
