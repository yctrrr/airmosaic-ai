CGE 从平衡的基年经济账户出发，加入明确的行为和市场出清方程。情景结果取决于生产与需求函数、弹性、闭合规则及施加的冲击；重现基年并不使结果自动成为观测到的因果效应。固定系数的核算方法见 [IO](../io/README_ZH.md)。

## CGE：从基年账户推导均衡

社会核算矩阵（SAM）表示基年经济。每列记录一个账户的支出，每行记录其收入；平衡后，每个账户的总收入等于总支出。投入产出表提供部门间流量，还需补全要素收入、居民、政府、储蓄、投资和贸易，才能形成完整 SAM。校准前应明确基年、地区和部门分类、单位及价格口径。

两个恒等式可以说明核算底层逻辑：对每个 SAM 账户，`总收入 = 总支出`；对每种产品，`国内产出 + 进口 = 中间使用 + 最终使用 + 出口`，具体还要遵循模型对库存和贸易的处理。恒等式限制结果，却不能单独决定价格变化后数量如何反应。

SAM 给出基年的货币流量与价值份额；实物数量还需要参考价格或其他数据。行为方程说明主体偏离基年时如何反应：企业在生产函数约束下选择投入，居民在预算内分配消费，使用者可以在国产品与进口品之间替代。CES 等函数形式描述替代方式；替代弹性来自外部证据或明确的假设，不能仅凭一张基年 SAM 识别。价格调整到产品和要素市场出清、机构预算平衡、生产满足模型定价条件。**闭合规则**进一步规定哪些变量固定、哪些变量调整，例如劳动供给、贸易差额及储蓄与投资；它是研究设计的一部分。

校准通过选择参数，使观测到的基年在参考价格下满足模型方程。比较静态模型在指定冲击后求一个新均衡；递归动态模型还用资本积累、人口、劳动供给和生产率等明确的更新规则连接各期。只有相关变量确实由方程决定，才称其路径为内生。核心比较是在相同核算定义和闭合规则下，对照基准与情景的结果。

## 常见概念

| 概念 | 建模时的含义 |
|---|---|
| 直接消耗系数与列昂惕夫逆矩阵 | `A[i,j]` 是部门 `j` 单位产出所需的 `i` 投入；`(I − A)^−1` 在所选系数下汇总直接和间接产出需求。 |
| 最终需求 | IO 表中的居民和政府消费、投资及出口；普通 IO 计算将其作为输入，CGE 则可由收入与价格决定其中一些部分。 |
| 生产活动与商品 | 生产活动代表生产者，商品代表产品或服务。分开建模可以表示一个活动生产多种商品，或多个活动生产同一种商品。 |
| 基年与校准 | 基年是参照经济；校准调整份额和尺度参数，使方程重现基年。替代弹性仍需独立依据。 |
| 内生与外生 | 内生值由方程求解，外生值由研究者给定。确定闭合规则后，改变外生值才能定义清楚情景。 |
| CES、Leontief 与嵌套 | CES 按指定弹性允许替代；Leontief 固定投入比例。嵌套结构规定每一层哪些投入可以相互替代。 |
| Armington 与 CET | Armington 常用于需求端区分国产与进口产品；CET 可用于把国内产出分配到内销和出口。两者都是建模假设。 |
| 计价基准（numeraire） | 固定一个参考价格或价格指数，确定名义价格尺度；价格变化应相对于它解释。 |
| 比较静态与递归动态 | 比较静态对照两个均衡，不刻画明确过渡路径；递归动态通过资本积累等状态更新逐期求解。 |

[IFPRI 标准 CGE 手册](https://cgspace.cgiar.org/server/api/core/bitstreams/a3854265-05a5-408f-9eb6-4c8583069553/content)逐项解释账户与方程；[GAMS MPSGE 入门](https://www.gams.com/latest/docs/UG_MPSGE_Intro.html)从小模型解释偏好、生产、价格和均衡。

## 用 GAMS 搭建不同的 CGE 模型

GAMS 是声明带索引的数据、变量和方程并调用求解器的语言，不是一套固定的 CGE 模型。建模可依次准备账户、部门和地区集合，平衡的 SAM 与基年价格，行为函数和弹性，方程与闭合规则，然后求基准解、施加情景并汇报结果。数据平衡与模型方程应分别可检查。[GAMS 的 SAM 平衡例子](https://www.gams.com/latest/gamslib_ml/libhtml/gamslib_sambal.html)展示一种处理方法，并非所有模型必经的统一算法。

常见的方程编写路径有两种。**代数式 GAMS** 显式声明 `Sets`、`Parameters`、`Variables` 和 `Equations`。[静态 `stdcge` 示例](https://www.gams.com/latest/gamslib_ml/libhtml/gamslib_stdcge.html)把其特定均衡写成以效用为目标的 NLP；[递归动态 `dyncge` 示例](https://www.gams.com/latest/gamslib_ml/libhtml/gamslib_dyncge.html)增加逐期循环并更新要素禀赋和资本。用 NLP 最大化福利是这些示例的设定，不是所有 CGE 的必备形式。代数式 **MCP** 则把零利润、市场出清、收入平衡等均衡不等式与变量配对。

**GAMS/MPSGE** 先声明生产部门、商品价格和消费者，再用基年流量与弹性描述生产和需求。在竞争性、规模报酬不变的结构下，MPSGE 生成均衡方程；表格表达不了的条件可通过辅助约束补充。典型源码含 `$MODEL`、`$SECTORS`、`$COMMODITIES`、`$CONSUMERS`、`$PROD`、`$DEMAND`，随后用 `$sysinclude mpsgeset`、生成文件的 include 和 `solve ... using mcp`。改变参数前应先核对基年重现。语法及其与代数式 MCP 的对应关系见 [GAMS 官方文档](https://www.gams.com/latest/docs/UG_MPSGE_Intro.html)。

搭建另一类模型，关键在修改经济结构与数据，不能只改 `solve` 关键字：

| 模型变体 | 需要增加或改变的结构 | 至少要检查什么 |
|---|---|---|
| 多区域 | 带地区索引的账户、地区间或国际贸易及地区层面的闭合规则 | 双边流量与各地区账户一致 |
| 递归动态 | 分期基准及资本等存量的状态转移 | 各期更新后的存量与流量衔接 |
| 多类居民 | 不同居民的要素所有权、转移、消费和储蓄 | 各类居民收支一致 |
| 环境领域 | 实物活动量与系数，以及明确的卫星核算或反馈机制 | 物理单位与环境核算恒等式一致 |

[世界银行对 MANAGE-WB 和 CGEBox 的说明](https://www.worldbank.org/en/programs/economicpolicy-macro-modeling/cge)提供单国与多国模块化设计示例；这些模型的模块和数据与 CHEER 分开。

## 如何选择并衔接两类方法

| 问题 | 直接起点 | 若要进一步解释，需要补充什么 |
|---|---|---|
| 指定最终需求由哪些上游部门支持，其隐含环境影响在哪里？ | IO／MRIO，附明确的系数和实物强度 | 检验最终需求、贸易映射和系数稳定性。 |
| 冲击如何同时改变价格、投入选择、收入、贸易和需求？ | 有明确 SAM、行为方程、闭合和弹性的 CGE | 说明并检验这些假设；结果以假设为条件。 |
| 全经济调整后，供应链影响如何改变？ | 先求 CGE 情景结果，再做 IO 或实物账户核算 | 对齐部门分类，避免同一直接或间接影响重复计入。 |

IO 表可提供 CGE 基年 SAM 的重要部分；CGE 情景求解后，IO 仍可用于详细的供应链归属。CGE 也可在不允许替代的层次保留 Leontief 结构。两者的关键差别是所用方程及固定了哪些量，不能简单说一种替代另一种。[CEEEA2.0 作者公开模型](https://github.com/Zhijie-Jia/CEEEA2.0-CGE)就是结合实例：先求均衡结果，再用 IO 计算隐含排放。

## 环境领域应用

CGE 环境应用要先建立经济账户与物理过程的映射，明确部门、地区、燃料或材料、年份及单位。**环境卫星账户**可根据 IO 产出或 CGE 活动量计算指标；这需要实物数量，或者从货币结果转换到实物量的可靠依据。卫星指标本身不会改变经济解。只有把物理量通过方程或约束接入生产、消费、资源、政策或生产率，才会形成反馈。

例如，记实物燃料使用量为 `Q[r,s,f,t]`，排放系数为 `EF[r,s,f,p,t]`，则卫星核算可写为 `E[r,p,t] = sum(s,f) Q[r,s,f,t] × EF[r,s,f,p,t]`。模型需要以明确的物理单位表示或推导 `Q`；系数及其含义仍需独立证据。若 `E` 进入总量约束或其他均衡方程，改变约束可能进一步改变 `Q`、价格和收入；若 `E` 只是事后报告的指标，则不会产生这种反馈。[世界银行 CGE 说明](https://www.worldbank.org/en/programs/economicpolicy-macro-modeling/cge)介绍了利用外部排放清单校准排放系数的做法。

编码前先选择连接方式。**单向核算**把物理强度系数用于 CGE 的活动量或能源结果。**内生扩展**可以在均衡方程中表示排放总量约束、资源约束、环境税、技术变化或气候影响下的生产率变化。与外部能源、土地、大气或健康模型**双向耦合**时，还需规定交换变量、单位、时空汇总口径，以及迭代或单次传递规则。不能把单向计算称为反馈，也不能在相连模型中重复施加同一冲击。

每个情景都应说明改变的参数或约束、基准值、发生时间和适用范围。先检验基年重现，再检查求解与模型状态、账户及市场平衡、物理恒等式，以及数量和价格变化的方向与幅度。报告弹性、闭合规则和环境系数的敏感性。输出保留模型版本、情景、年份、地区、部门、单位和分类映射；外部模型沿用自身的定义与验证。求解成功本身不能证明环境结果可靠。

## 可运行模型与外部 CHEER 实例

[CGE 技能](../../../../skills/model/01_socioeconomic_natural_change/cge/SKILL_ZH.md)内有独立编写的合成封闭经济数值教学模型。它从平衡 SAM 出发，校准生产和家庭预算份额，固定工资计价基准，复现零冲击均衡，再求解生产率情景。中间投入比例固定；劳动和资本通过 Cobb-Douglas 增加值函数调整，家庭消费随收入和价格变化。单向排放系数在求解后计算卫星指标。这说明计算流程，不能视为校准后的中国模型或 CHEER 复现。该教学模型不含贸易、政府、投资、多家庭或动态；扩展这些内容必须添加账户与方程，而非仅增加 SAM 行。

## 以 CHEER 为首个操作范例

CHEER 是模型系列；GAMS 是建模平台，MPSGE 是 GAMS 的均衡建模子系统，MCP 是求解类型。公开的 CHEER 与 CHEER-P 文件是演示包，不能把后续版本说明直接当成演示代码的功能。已审阅的 CHEER-P 演示代码声明 2012 年基期、30 个地区标签和 11 个部门，而 [CHEER-P 官网](https://cheer.org.cn/model-structure/extension/)说明的较新版本为 2017 年基期、31 省。不同版本的环境变量和方程可能不同，应核对实际启用的源码。

[CGE 技能](../../../../skills/model/01_socioeconomic_natural_change/cge/SKILL_ZH.md)说明模型搭建、源码映射、可选的人工复现和环境情景检查；[CGE 模型拓展](../../../../skills/model/01_socioeconomic_natural_change/cge/references/model-extension-cases_ZH.md)进一步按分类、校准、行为、均衡、动态、环境和报告模块说明修改顺序。CHEER 是目前已审阅的实例。主要依据：[CHEER 下载页](https://cheer.org.cn/downloads/)、[CHEER 模型分支](https://cheer.org.cn/model-structure/extension/)、[GAMS MPSGE](https://www.gams.com/latest/docs/UG_MPSGE_Intro.html)及 [GAMS 模型与求解语义](https://www.gams.com/latest/docs/UG_ModelSolve.html)。

公开的[一般均衡模型构建技能](https://github.com/brycewang-stanford/Auto-Empirical-Research-Skills/blob/main/skills/31-thalysandratos-claude-code-skills/_skills/theory/general-equilibrium-model-builder/SKILL.md)为先定义主体、禀赋和市场出清、再计算的顺序提供参照。该技能当前用 Julia 实现纯交换经济；CHEER 的生产、SAM 校准与 GAMS 求解仍需分别按源码审阅。
