# CEADs 能源与折标煤

**状态**：本次阅读本地能源项目 README 和 `script/ceads_energy.py` 的处理/校验入口；近期有来源版本与换算口径核对记录。该脚本未复制到 AirMosaic，当前无 tool_id。

## 输入、依赖与输出

输入包括 CEADs 原始省级部门能源工作簿、明确版本的全国/省级能源平衡表及换算附录。依赖 Python、pandas、openpyxl、pyarrow；本地处理不需要登录，获取原件的授权另核对。

输出分为原单位实物量、折标煤明细、部门/能源份额，以及来源哈希、系数审计、闭合检查和版本差异。保留原始负值及无法定义的分母状态，不能一律改零。

## 操作步骤

1. 固定原件版本并记录哈希；新旧发布版分开对比，不混拼成一个连续面板。
2. 核对最终消费、转换投入/产出、损失和非能源用途，选定实际统计分母。
3. 保留原始 source_value 和单位，单独建立 year–fuel 换算系数及来源、代理年份、适用范围。
4. 换算到统一标准煤单位；复合能源先检查组成和加权规则，再计算系数。
5. 按省年能源核对部门合计，输出份额时防止居民总计与城乡明细重复相加；分母为零时保留 undefined。
6. 将与年鉴的差异留在核对表，不用参考表覆盖原始 CEADs 数值；先验证新一代输出再发布完成标记。

## 本地方法中必须保留的区别

当前来源项目处理 47 个最终消费部门、20 种能源。1997–2018 使用“全国统一值”：每种能源一个跨省跨年的换算值，主要参考 2019 年全国最终消费比值；不是所有能源共用一个系数，也不是每年/每省实测热值。洗精煤和其他能源有明确例外；2019–2022 使用各年对应依据。该规则是已核对项目的具体方法，迁移到新年份须重新评估，不能默认为通用规则。

原入口支持 `--root`，但会依其固定结构构建结果并维护 generation/完成标记；这不是支持任意 output_dir 的 run-tool 适配器。迁移前需把 raw/reference 与新任务输出分开，禁止让新试验覆盖原项目已验收结果。

本次没有运行处理脚本或重算数值；来源指纹见[来源记录](../SOURCES.md)。
