# ERA5：气象协变量与输入资料获取

**主阶段：03_atmospheric_transport。适用阶段：03、04。状态：reference；tool_ids 为空。**

ERA5 可作为气象背景、暴露研究协变量或模型输入适配的资料来源。操作入口是 [era5-acquisition skill](../../skills/data_acquisition/03_atmospheric_transport/era5/SKILL.md)，账号、目录、请求示例、下载与验收统一见 [Copernicus 下载指南](../../harness/usage/copernicus-downloads.md)。这里只登记一张方法卡，04 引用它，不复制实现。

## 选择与使用步骤

1. 地表或近地表气象先核对单层产品；垂直气象场另选气压层或模式层。ERA5-Land 是独立产品，不能替代全部大气变量。
2. 固定变量定义、时间范围、UTC 时次和区域。日统计需求要先确定统计量、时区及完整采样，不能把每日下载文件当作日平均。
3. 在 CDS 表单选择参数并生成 API 请求，与公开示例对照；先做参数审查，真实下载属于后续有范围的任务。
4. 小批次下载验收后再按日/月、变量和层次拆分。保留原文件，转换、重采样和时间汇总写入新产物。
5. 向下游交接数据集、变量/层次、UTC/当地时间处理、单位、网格、缺失和产品版本。使用近期数据需记录是否为初步发布版本。

## 方法限制

- 温度、降水、通量不能统一套用同一种单位转换或时间汇总；累计量先查累计时段。
- ERA5 不能直接替换任一 GEOS-Chem 版本所需的驱动文件，另行审查模式输入结构和预处理链。
- 与 [PM2.5 站点方法](pm25_stations.md)配合时，气象协变量、站点观测和派生匹配结果分开保存；不能直接继承站点或气象产品的时间/单位假设。
- 本地历史接口仅用于发现“按日期分批”的需求；固定行号替换模板、旧格式字段和机器专用目录不复制进项目。
- 本次仅核对官方文档、公开表单和旧脚本接口；未读取原始数据或验证下载成功。来源和复核日期见下载指南。
