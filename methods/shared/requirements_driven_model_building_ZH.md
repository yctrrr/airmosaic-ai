# 如何把研究要求转为模型设计

[English](requirements_driven_model_building.md) | **中文**

“根据这些数据构建模型”仍留有多项科学选择。先解决会改变结果含义的选择，再决定软件实现。

## 描述问题

写明结果或目标、观测单位、总体、时期和测量单位，解释结果用于预测、比较、解释、因果估计还是复现。

| 选择 | 需要回答 |
|---|---|
| 数据 | 哪个固定来源和版本代表预期总体？ |
| 变量 | 哪些预测变量在使用时可获得，哪些具有因果或识别角色？ |
| 约束 | 模型需要满足哪些假设、基线和科学要求？ |
| 评估 | 留出应代表哪些新实体、区域或时期？ |
| 判断 | 什么证据能说明结果有用、受限或尚无定论？ |

先利用变量字典解决术语问题。只有目标名称，不能确定汇总、物理单位或测量支持范围。

## 选择构建或复现

构建新模型时，按问题选择已支持的方法并说明适用理由；复现时，固定特定参考流程、数据契约及数值比较准则。已有代码提供参考实验，其设置不是所有任务的默认值。

例如，论文的站点回归和调参设计不能换成方便的通用划分后，仍声称完成相同复现。[复现方法](model_reproduction_ZH.md)说明如何比较这些设计。

## 规划可靠评估

选择基线、开发预算和最终留出。重复实体、空间依赖、时间顺序与重叠滞后会影响隔离；学习型变换在训练数据及有关训练折内拟合。

指标应对应结果与用途。不同候选尽量使用可比总体，并报告剔除。约定测试前冻结最终选择。

## 决定如何解释

模型解释关注拟合预测如何依赖输入；因果估计关注识别假设下的明确处理对比。选择控制变量或解释工具前先确定要回答哪个问题，细节见[回归设计](machine_learning_model/README_ZH.md)。

## 交接具体任务

交接固定输入及字典引用、目标定义、变量角色、划分依据、候选要求、计算预算、结果位置和复核准则，明确缺失整理或不支持方法。

选定[技能](../../skills/model/shared/README_ZH.md)将这些选择映射为参数和代码，[工作流](../../workflows/ml_regression/README_ZH.md)组合经审查的操作，具体研究在[项目](../../projects/README_ZH.md)记录实验与判断。
