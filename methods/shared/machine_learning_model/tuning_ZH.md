# 不使用最终测试集的自动参数选择

[English](tuning.md) | **中文**

自动调参依据开发数据上的表现，在声明的搜索空间内选择设置。它不负责确定科学目标、论证物理变量、补足站点元数据，也不建立因果效应。搜索空间和计算预算仍是研究决策，遵循[模型规划](../model_planning_ZH.md)与[参数机制](models/README_ZH.md)。

预测未布站位置时，开发折的空间分组应对应预期迁移用途。同一站点身份的记录应保持在一起，同时检查相邻站点和共享网格输入造成的依赖。分组代码能核对传入分组，不能证明空间独立性。调参前固定最终留出站点，不能为了提高分数而随机拆站点日。

[mlr3 调参教材](https://mlr3book.mlr-org.com/chapters/chapter4/hyperparameter_optimization.html)区分内层参数选择与外层评估。有独立最终测试集时，可在开发数据内交叉验证调参，再用所选设置拟合开发总体，最后评价冻结测试。如果采用外层重抽样，每个外层训练子集都需分别调参并拟合学习型预处理。内层最优分数不是独立测试精度。

依据训练覆盖、独立空间单元、变量角色和计算约束提出范围。少量随机搜索是可审计的初始路线，不保证全局最优；贝叶斯或多保真优化需独立依赖与评估协议。包允许的搜索次数不等于科学依据。[森林参数综述](https://doi.org/10.1002/widm.1301)可帮助理解哪些设置影响灵活性与稳定性，不规定普适最优树数。

预算应计入重抽样与最终重拟合：单模型在 K 个固定开发折上比较 E 个候选，最多需要 E×K 次拟合，再加一次最终拟合。重复种子、其他模型族及外层折会进一步增加成本。调参的时间终止器未必限制最终拟合，实际进程上限是独立操作控制。

数值污染预测在冻结测试样本上报告保留浓度单位的 RMSE、MAE，以及 `1-SSE/SST` 定义的 R²。各方案使用共同测试 ID、相同排除规则与单位，并比较开发训练均值基线。R² 不等于相关系数平方，可以为负。查看测试结果后再改变量或搜索方案属于新的研究决策，不是继续使用未触碰的测试集。

实际 API、完整数值输入限制、准确预算及当前验证状态见[自动调参技能说明](../../../skills/model/shared/machine_learning_model/references/automatic-tuning_ZH.md)。已注册的固定候选工具保持原行为，直接 R 助手不增加执行器适配器。
