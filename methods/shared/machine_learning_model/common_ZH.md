# 问题、变量、抽样与评估

[English](common.md) | **中文**

## 生成实验代码前

先提交[建模方案](../model_planning_ZH.md)，说明目标、逐变量依据、参数范围、划分、预处理、评估和解释，提供理由、证据、备选与不确定性供人类判断。默认等待；用户明确委托后才交由代理审定。生成实验代码前保存获准方案，执行前再次核对代码、任务与数据。
## 1. 先说清楚想知道什么

先写一句话，例如“估计未布站区域的日均浓度”，或“估计某个驱动因素变化时浓度如何改变”。它们需要不同的设计：

| 目标 | 主要结果 | 首先要决定的内容 |
|---|---|---|
| 预测 | 新样本上的预测及误差 | 预测谁、哪里、何时，以及当时能获得哪些变量 |
| 解释已拟合模型 | 模型使用的变量与响应规律 | 解释代表什么总体和参考条件 |
| 估计因果效应 | 指定处理对比下的结果变化 | 处理、结果、时间顺序、共同原因及识别假设 |

区域环境预测通常面向监测未覆盖的地点、时期，或无法直接观测的时空变量。先定义空间支撑尺度、平均时期、单位和实际用途。已有观测提供训练标签与留出验证参照，它们与待预测的未观测区域分别定义。区域日均场与明日逐小时浓度，需要不同信息和验证方式。

如果目标本身无法观测，要说明标签是代理量、模拟值还是推导估计。与这些标签一致，首先说明模型符合所用参照，不能直接等同于对真实物理量的准确预测。
## 2. 准备每一行含义清楚的数据表

每行需要唯一的样本标识、实测或推导的结果、候选变量，以及足够的位置和时间信息来设计评估。记录来源、单位换算、汇总规则与缺失情况。

检查表格是否连接到了正确站点和时期，区分缺失观测与实测零值。依据来源的质量规则调查不合理数值，保留剔除记录，让其他研究者知道最后研究的是哪些样本。

缺失处理要适合研究问题。用训练数据估计特征填充值可以支持预测；不能通过制造目标值来增加样本量。凡是从数据中学习的变换，都应避免使用留出观测。
## 3. 先选择变量，再选择模型

有用的变量应有明确科学角色、足够的测量质量和合适的时间。预测问题关注实际预测时能否获得；因果问题关注它与处理、结果之间的关系。

逐项定义变量的物理量、单位、高度或层次、空间尺度和时间窗口，区分实测或模拟物理量与统计代理量。相关性或预测价值本身不能确定因果角色。

| 角色 | 它会改变什么决策 |
|---|---|
| 预测变量 | 在实际使用时可获得的条件下，能否改善预测？ |
| 共同原因 | 为处理与结果之间的混杂，是否需要考虑它？ |
| 中介 | 研究总效应，还是排除这一中间过程的路径？ |
| 碰撞点 | 对它筛选或调整，是否可能引入关联？ |
| 标识或目标派生字段 | 它是否泄露答案或编码了样本划分？ |

缺失率、变异、相关性和 VIF 用于诊断候选集合，诊断在训练数据内完成。变量冗余时，依据科学含义和测量质量决定保留谁。预测重要性低，不足以成为删除必要混杂因素的理由。

具有空间结构的变量还需检查可迁移性：两两相关性或 VIF 较低，不能证明模型可用于采样地点以外。[空气污染特例](../air_pollution_regression_ZH.md)说明了坐标等地理代理变量的文献依据与比较方式。

### 划分前核对产品生成来源

区域预测常使用再分析、观测融合产品，或合成、模拟场。逐项记录产品版本、来源观测、同化或融合及校准方式，核对是否使用了结果变量、评估站点和时期。合成数据生成器或上游模型是否利用了评估标签，也要检查。再分析结合模型与观测，具体输入随产品及变量而异；可参照官方 [ERA5](https://www.ecmwf.int/en/forecasts/dataset/ecmwf-reanalysis-v5) 与 [EAC4](https://www.ecmwf.int/en/forecasts/datasets/cams-global-reanalysis-eac4) 说明。

如果上游特征已使用留出的目标观测，下游再划分表格不能恢复独立验证。可行时采用未参与产品生成的独立观测、排除评估站点或时期及折外生成的产品，或删除有关特征进行敏感性比较。无法确认独立性时，应报告限制，不能声称完成独立测试。

分别记录数据对应时间与实际发布、可获得时间。回顾重建可按声明的设计使用后来发布的产品；预报必须遵守预测起点的信息边界。将此前观测同化到当时可用的预报初始场，并不自动构成泄漏，应结合实际用途和产品来源判断。
## 4. 留出能代表实际用途的评估样本

训练数据用于拟合，验证数据用于选择变量、模型与设置，最终测试用于评估冻结后的方案。

数量与比例根据可用数据规模、有效独立样本数、时空结构及评估所需精度确定，没有统一比例或固定样本数。独立样本较少时，可考虑适当的重抽样设计，并先确认其实现支持。计算上限另行决定，不能在未说明时改变评估总体。

预测既有站点的后续时期，可考虑向前时间留出；预测新站点或地区，应留出相应站点或区域。注意重复测量与重叠时间窗口。随机按行划分可能使高度相关的观测分布在两侧，实际回答的问题比预期用途更容易。

选型前固定测试总体。使用交叉验证时，学习型预处理应在每个训练折重新拟合。不同方案尽量在相同样本总体上比较。

[Roberts 等（2017）](https://doi.org/10.1111/ecog.02881)说明了考虑依赖结构的必要性，也指出过严的分块可能将插值评估变成外推评估。距离、分组和时间间隔应依据预测任务及开发数据结构确定，不能把文献中的分块尺度当成通用独立性阈值。
## 8. 回到原问题审查结果

使用[公共评估参照](evaluation_ZH.md)进行各模型族共用的训练均值对照，将它与 R² 中测试均值的归一化区分开。

有用的报告应让读者知道：用了什么数据和样本，比较了哪些变量与模型，冻结方案在预期留出总体上表现怎样，支持何种解释，还有哪些假设或不确定性。

这些依据保留在具体研究中。配置、脚本执行和产物读取见[技能操作](../../../skills/model/shared/machine_learning_model/references/operations_ZH.md)。浓度驱动、气象归一化和下游影响继续阅读[空气污染特例](../air_pollution_regression_ZH.md)。与已发表综述的方法对应关系见[来源映射](../../../skills/model/shared/machine_learning_model/references/published-basis_ZH.md)。
