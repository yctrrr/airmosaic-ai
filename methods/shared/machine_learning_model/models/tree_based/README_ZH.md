# 树模型

[English](README.md) | **中文**

[决策树](decision_tree/README_ZH.md)和[随机森林](random_forest/README_ZH.md)共享通过划分变量空间预测的结构。单棵树给出一组局部规则，森林通过平均随机化树提高稳定性。结合科学问题、样本支撑、预测稳定性和计算预算选择。

比较时保持变量组、样本键、预处理及评估群体可比。同属树模型不代表 R/Python 的参数含义或数值产物可以互换。[模型比较](../README_ZH.md)保留参数选择的文献依据。配置与代码归[树模型技能目录](../../../../../skills/model/shared/machine_learning_model/models/tree_based/README_ZH.md)，均值参照归[公共评估](../../evaluation_ZH.md)。
