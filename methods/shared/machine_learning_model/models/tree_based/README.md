# Tree-based models

**English** | [中文](README_ZH.md)

[Decision trees](decision_tree/README.md) and [random forests](random_forest/README.md) share a partition-based predictor structure. A single tree gives one set of local rules; a forest averages randomized trees for greater stability. Choose between them using the scientific question, sample support, prediction stability and computational budget.

Keep variable groups, sample keys, preprocessing and evaluation population comparable. Shared ancestry does not make parameter meanings or numerical outputs interchangeable across R/Python implementations. [Model comparison](../README.md) retains the cited parameter-selection evidence. Configuration and code belong to the [tree-model skill directory](../../../../../skills/model/shared/machine_learning_model/models/tree_based/README.md); the mean reference belongs to [common evaluation](../../evaluation.md).
