# Linear regression

**English** | [中文](README_ZH.md)

A linear predictor is a useful parsimonious comparison when additive relationships approximate the question. Review transformations and variable meanings, inspect residual structure and assess extrapolation. Correlated predictors can make coefficient interpretation unstable even when prediction is adequate. Predictive fitting alone supplies neither causal effects nor inferential uncertainty. Compare complexity against the intended spatial/time holdout, not training fit.

Parameter reasoning and cited evidence: [model comparison](../README.md).

Only the Python ordinary linear predictor is currently enabled; regularized variants and R linear regression are not exposed by the registered adapters.
