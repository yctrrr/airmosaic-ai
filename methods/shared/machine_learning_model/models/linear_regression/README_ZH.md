# 线性回归

[English](README.md) | **中文**

当加性关系可近似研究问题时，线性预测器可作为简洁的比较模型。核对变换和变量含义，检查残差结构及外推。相关变量可能使系数解释不稳定，即便预测仍可用。预测拟合本身不提供因果效应或推断不确定性。应依据目标时空留出表现比较复杂度，而不是训练拟合。

参数理由和文献依据见[模型比较](../README_ZH.md)。

当前注册适配器仅启用 Python 普通线性预测器，未暴露正则化变体或 R 线性回归。 配置、代码调用及当前检查见[对应技能](../../../../../skills/model/shared/machine_learning_model/models/linear_regression/README_ZH.md)。
