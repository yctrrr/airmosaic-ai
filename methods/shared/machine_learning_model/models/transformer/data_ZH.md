# Transformer 的不同数据类型处理

<!-- README-I18N:START -->

[English](data.md) | **中文**

<!-- README-I18N:END -->

先阅读[架构方法](README_ZH.md)。数据准备应保留观测的科学含义，而不只是生成软件能够接收的矩阵。以下为研究设计建议，不表示某个模型同时支持全部输入类型。

## 1. 定义输入单元

| 数据 | 有意义的单元与表示 | 主要处理决策 |
|---|---|---|
| 静态或汇总表格 | 同一样本中的变量；数值与类别特征可采用不同嵌入 | 唯一样本键、变量身份、单位、缺失和类别定义；行顺序不是时间轴 |
| 规则时间序列 | 一个时刻或连续时间片段 | 实体、频率、历史范围、目标时段、预测起点、缺口与变量可得性 |
| 空间场或遥感网格 | 空间片段、网格单元或受支持的点表示 | 坐标系、网格、单元支撑、分辨率、质量掩码及所需输出支撑 |
| 随时间变化的空间场 | 空间单元结合历史时间信息 | 时空对齐、缺测覆盖、输入区域及计算可承受的注意力范围 |
| 文本或文档 | 带文档及来源身份的文本单元 | 语料、截断、文档重叠、发表时间及所用预训练表示 |
| 观测与模型产品混合输入 | 按明确的键或支撑对齐的独立表示 | 物理变量、来源及版本、信息可获得时间，以及明确的融合方式 |

[FT-Transformer](https://arxiv.org/abs/2106.11959)提供表格特征例子，[PatchTST](https://arxiv.org/abs/2211.14730)提供时间片段例子，[视觉 Transformer](https://arxiv.org/abs/2010.11929)提供图像片段例子。最后一项研究针对图像识别，不是已经验证的大气空间场预测器。用于大气研究还需单独设计目标、几何关系、输出层和验证。

## 2. 建立科学数据约定

表示学习前，记录样本或实体键、目标及参照质量、各变量的物理量与单位、空间和垂直支撑、时间窗口、来源及版本、可获得性。区分静态属性、已观测历史和确实已知的未来协变量。数据对应的有效时间与实际发布或起报时间分别保留。

按[通用设计](../../common_ZH.md)核查产品来源。如果再分析、融合产品或上游模型已使用评估观测，下游划分本身不能恢复独立性。业务预测中，不能直接用事后观测或回顾性再分析替代历史预测起点可用的协变量。回顾重建可以使用不同的信息集合，但必须明确说明。

保留来源数据，引用已有[资产版本](../../../../../harness/assets_ZH.md)，记录变换及样本归属，派生版本按项目审核流程建立。数组缓存不能仅因文件格式不同就视为独立科学数据集。

## 3. 按数据结构处理，不改变研究问题

### 表格

样本键用于关联与评估，不能意外成为透露答案的预测变量。数值缩放、类别词表、缺失处理及变量筛选使用训练数据拟合，并声明未见类别的处理方式。变量身份很重要，但不能将任意列顺序解释为时间距离。没有真实时间观测，就不能把站点汇总表转换成时间预测任务。

### 序列

在每个实体内处理重复记录、时区和采样间隔。不能删除内部缺测时刻后，把剩余行假定为等间隔。应显式保留缺口，选择有依据的规则化或插补方法，或使用支持不规则时间的实现。

先固定实体和时间边界，再构造窗口。训练标签不能跨入验证或测试目标时段。留出预测可以使用该起点实际可获得的较早上下文；共享历史上下文不同于把留出标签暴露给拟合或选型。声明窗口步长及重叠预测的汇总方式。

一种输入输出描述为 `X_history: [B, L, F]` 与 `Y: [B, H, D]`，其中 `B` 为批量大小，`L` 为历史长度，`F` 为特征数，`H` 为预测长度，`D` 为目标数。已知未来协变量需要独立约定以及支持它的模型。每条预测保留实体、起点、有效时间和时效。这些轴表示科学含义，不保证各模型具有相同接口。

### 空间与时空场

对齐前核对坐标、经度表示、垂直层次、分辨率及各物理量的支撑。根据变量定义选择插值、面积加权或守恒方法。保留质量和覆盖掩码，说明片段化引入的聚合。地理网格评估需考虑纬度导致的面积差异和片段实际物理尺度。

输入、输出和评估网格可以不同，但映射关系必须明确。按应用目标留出站点、区域或时段，考虑片段重叠及邻近片段共享的信息。所需隔离带依据科学独立性分析确定，不能统一规定为某个片段大小。另见[空间方法](../../../spatial_analysis_ZH.md)。

### 多源输入

按明确的实体、时间和空间支撑对齐，不能只按数组位置拼接。区分共同预处理、不同来源的独立编码器和交叉注意力，说明静态、粗分辨率与细分辨率输入如何衔接。某产品缺失覆盖不能悄然按零处理。使用交叉注意力不证明物理一致性或因果机制；[TimeXer 方法](../time_series/timexer/README_ZH.md)只是其中一个更窄的例子。

文本用于辅助信息时，保留文档来源、版本和发表时间，检查是否透露目标标签或重复评估文档。文本分词器本身不能定义连续数值变量合适的物理表示。预训练表示还需记录训练范围，评估是否可能与验证材料重叠；未发现重叠不等于证明独立。

## 4. 区分掩码并检查准备后的数据

观测掩码标记缺失或质量不合格值，填充掩码标记不存在的序列位置，注意力可见性规则控制表示之间能否交互。三者不能互相替代，注意力掩码本身也不能修复非有限输入。缺失目标不能悄然变成零值训练标签。未来预测与回顾性缺测重建允许使用的信息也不同。

核对行数及实体数、唯一键、目标单位、数组轴、划分归属和排除记录。检查预处理能否用于新输入、时空对齐是否保留，以及任何来源是否引入留出目标信息。重采样、质量阈值、代理标签、未来协变量或缺失目标的未决选择，应写入[建模计划](../../../model_planning_ZH.md)，不能藏在数据加载器默认行为中。

先完成这些方法决策，再选择软件实现。本页不定义可执行脚本或新增的任务模式字段，实际支持仍以[技能](../../../../../skills/model/shared/machine_learning_model/SKILL_ZH.md)声明为准。
