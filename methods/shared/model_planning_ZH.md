# 生成实验代码前先提交建模方案

[English](model_planning.md) | **中文**

建模方案让人类在代理把科学选择转成实验前判断是否合理。方案记录显式理由和证据，不记录隐藏思考。起点是本次问题和获授权数据，不能直接把旧任务配置当成新方案。

## 方案需要解释什么

| 决策 | 必要依据 | 人工判断重点 |
|---|---|---|
| 目标 | 物理量、单位、时空尺度、未观测预测区域、实测或代理标签及用途 | 参照是否代表研究问题；目标是预测、模型解释还是因果估计 |
| 变量 | 每个纳入变量的角色、物理或代理含义、纳入与排除理由、单位、测量尺度、可获得性和产品来源 | 是否遗漏重要过程；同化、融合观测、目标派生列或未来信息是否泄露答案 |
| 参数 | 候选模型、有界范围、实际比较点、固定设置、默认值及版本假设、计算预算 | 哪些来自机制、文献或训练诊断，哪些只是工程起点 |
| 划分 | 独立单位、时间、空间或分组边界、来源与可用数量、最终测试保护及抽样理由 | 留出是否代表实际用途；不存在通用数量或比例 |
| 预处理 | 单位、缺失标记、剔除、填补、编码、变换、未知类别及训练或逐折拟合边界 | 替换是否保持物理含义；是否调查极值而非静默修改 |
| 评估 | 基线、选型损失、冻结比较、子群及残差检查、验收标准 | 损失是否符合应用；最终测试是否隔离于设计和调参 |
| 解释 | 对应拟合模型、参照总体、解释预算、不确定性及适用时的因果识别 | 证据是否支持所提解释；预测重要性本身不识别效应 |

参数范围要区分“参数含义的依据”和“该取值在本数据上合适的依据”。官方手册不能证明所选树数最优，应记录备选项与不确定性。历史成功实验仅作参考，沿用设置需要本次问题的理由。

参数的文献与数据条件比较见[回归选择依据](machine_learning_model/README_ZH.md)，空间代理变量的选择见[空气污染特例](air_pollution_regression_ZH.md)。每个拟定变量与取值，都要区分文献发现、本研究推论和待获取证据，附具体来源及适用于本数据的理由。共用一条引用或重复通用句子，不能替代逐变量依据。同时说明哪些比较已受实现支持，哪些仍需适配。

计划阶段可只读检查获授权字典、样本键、划分规模和开发集特征，不用最终测试目标值设计特征或候选。说明诊断对应全部开发记录，还是最终实际保留的训练队列。

## 审核节点

1. **生成实验代码前：**提交方案、备选与未解决事项，默认等待人工审核。保存获准方案的准确身份及允许操作。
2. **执行前：**核对生成或复用的调用代码、任务绑定、数据身份、语法、范围、合成测试、依赖和预检。已有批准已覆盖执行时，无需再次询问同一权限；内容变化需重新检查。
3. **结果后：**科学有效性、限制和复用与计算成功分别判断。查看最终测试后提出的修改属于新实验，不能继续用同一测试选参。

阻塞性未知项使受影响操作停止。已声明的限制可以在结论受限时允许有界技术实验，但须记录判断，不能将缺乏依据的假设填成真。

## 人工审核与授权代理判断

默认由人类审核。用户明确委托判断后，代理可在该范围内审定并推进。保留非秘密的用户授权引用、计划身份、允许操作、审核时间、代理判断及限制。计划中的字段、命令行自动标志或代理自身声明，都不能代替用户授权。

人类阅读方案后，只需回复批准、修改、拒绝或委托判断，由宿主代理把真实答复形成记录，无需人类编辑 JSON。明确答复涵盖哪些操作；只批准生成时，仍不能执行。

获准计算不代表科学验收、发布、凭据访问或数据入库。问题、变量、参数范围、划分、预处理或输入版本改变，会改变计划身份并使旧审核失效；生成代码改变后需重新做技术检查。
