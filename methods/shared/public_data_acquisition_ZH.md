# 公开科研数据获取

[English](public_data_acquisition.md) | **中文**

从论文数据可用性声明、补充材料、DOI 或 Zotero 已有条目追溯来源。分别记录生产者、发布仓储、数据标识符、版本和文件标识符。在发布记录核实覆盖范围、变量、单位、发布日期和使用条件。对年度数据，分别核对观测或统计年份和目录发布日期。

按任务划定文件范围。下载后核对发布方提供的字节数或校验值，再验读实际文件格式和内容。解包、裁剪时记录原文件和处理后文件的 SHA-256 以及转换方法。原网格裁剪沿原像元选取范围并保留像元值、分辨率和原点。其他转换在来源记录中注明所用的重采样方法。

获取命令和常用数据入口见[公开数据获取技能](../../skills/data_acquisition/shared/public-data/SKILL_ZH.md)。

裁剪范围应覆盖下游研究区。将裁剪 TIFF 与来源回执一同保留，便于后续核对产品、统计年、发布版本及实际范围。原网格裁剪保留源像元。分析所需的汇总由下游工作流完成，例如在人均 GDP 特征中先按同一空间范围汇总夜光和人口。

夜光示例中，Harvard Dataverse 是发布仓储；研究团队的跨传感器协调序列区别于原始卫星辐亮度。[数据 DOI](https://doi.org/10.7910/DVN/YGIVCD)在 [Chen 等（2021）数据论文](https://essd.copernicus.org/articles/13/889/2021/)后仍有版本更新，应记录实际发布版本，不能从论文标题推断单位。[ORNL LandScan Global 方法说明](https://www.nature.com/articles/s41597-025-04817-z)将其定义为 30 弧秒环境人口计数；年度来源和模型变化也影响跨年可比性。GDP 将该环境人口作为代理权重，可能不同于官方人均 GDP 的人口分母。[CDS 土地覆盖记录](https://cds.climate.copernicus.eu/datasets/satellite-land-cover)另有产品版本和质量标志。年度一致不能消除这些测量差异。

官方 API 必须返回有效元数据。若返回访问页面、仓储临时故障或目标年不可用，应停止获取；不能关闭 TLS 校验或静默替换产品。常用目录区分自动获取、官方客户端辅助和人工路线。Zotero 提供发现和附件线索，不代表数据获取及再分发的一般授权。
