# 治理成本与分配情景

**状态**：本次核对本地成本项目的编号流程、单位成本接口与资源约束。它仍是有专用输入和验收条件的 R 管线，AirMosaic 没有可调用的整套 01–04 运行器。

| 阶段 | 方法用途 | 交接时检查 |
|---|---|---|
| 01 单位成本 | 样本、单位、年化、运维与 ULE/BAT 端点 | 活动单位、价格年、组件是否重复计费 |
| 02 历史台账 | eta/活动匹配、历史成本、网格和企业分配 | 源只计一次、精确 ID、原始与成本 eta、守恒 |
| 03 全国情景 | 全国目标成本池、实际落实成本、排放情景 | 02 历史存量与新增成本分开，同一代成本—排放配对 |
| 04 分配情景 | 公平性、转移与约束下的成本及排放 | 预算、承接主体资格、物理上限和目标闭合 |

## 操作步骤

1. 固定研究问题、主口径、成本边界和情景注册表；经济转移支付与社会资源成本分别解释。
2. 冻结源码、输入及同代 manifest；明确哪些阶段可复用，不能混用不同代成本表和排放表。
3. 对单位、基准价格、寿命、贴现、能源/工资代理和组件配对逐项核对。统计比值校准不是可无条件套到所有部门的单位成本修正。
4. 先验证小范围键、预算和分配守恒，再按已授权范围执行；每阶段检查产物和失败记录。
5. 下游只消费满足其契约的上一阶段输出。身份识别/导入、文件存在、某个测试通过都不等于物理资格或整套分配验收。
6. 保留基准与情景成对结果，明确增量、总量和空间口径，再生成比较图表。

## 运行和复用边界

原项目约束要求资源申请尽量匹配实际并行负载，不能只增加申请核心数；已有运行或排队任务保持冻结版本。此次整理没有查看调度状态、登录服务器、修改源码或启动新作业。

本地流程按单位成本、历史台账、全国情景和分配情景组织。迁移前需拆清输入契约、资源预算、输出目录和允许的操作；本库不提供“直接 source 全流程”的快捷命令。

参数/样本、生产台账和完整调度日志留在原工作区；仅将已核对的通用公式、边界和脱敏验证摘要共享。
