# 人口与基线健康数据的对齐

[English](population_health.md) | **中文**

健康影响估计需要相容的人口、基线结局、暴露与风险函数；各文件取得并不证明口径相容。空间人口估计见 [WorldPop 方法](../01_socioeconomic_natural_change/worldpop_ZH.md)，基线健康估计见 [GBD 方法](../04_integrated_impacts/ihme_gbd_ZH.md)。

暴露反应系数或曲线应另从发表来源取得，按[健康影响方法与技能](../04_integrated_impacts/health_impacts_ZH.md)核对。基线死亡率导出不是风险曲线。接入上游预测前，匹配污染物、暴露统计量与时段、单位、结局和适用人群；不能通过改列名，把 PM2.5 响应用于臭氧预测。

## 确定共同研究人群

明确地区/边界版本、年份/参考日期、年龄边界、性别及病因。WorldPop 与 GBD 可能使用不同总量基准和年龄结构，选定参考口径需说明依据，不能默认分母可交换。优先全期使用相容发布版，估计修订与真实变化分别解释。

| 数量 | 对齐要求 |
|---|---|
| 人口数量 | 人数/密度单位、参考日期、网格/边界、年龄/性别覆盖 |
| 基线死亡 | 病因层级、数量或率、年龄/性别和地区定义 |
| 基线率 | 分母及单位尺度；年龄标准化率不能重建实际死亡数 |
| 浓度 | 暴露时段、空间支持与人口分布 |
| 风险函数 | 适用病因/年龄、浓度单位、暴露窗口和反事实 |

年龄别基线率 `r` 若为每十万人，匹配人口为 `P`，则预期基线死亡为 `P × r / 100000`。仅适用于粗率或匹配年龄别率，不能把年龄标准化率乘实际人口。构建总体率时先合计死亡数和人口，不直接平均分组率。

## 覆盖与不确定性

年龄、性别和地区互不重叠，不把总计与分项相加。缺失组合与零分开，检查分组合计、空间处理前后人口守恒，以及浓度/人口网格一致性。

分别保留基线、暴露和风险的不确定性。总量和差异需要有依据的依赖结构或相容联合抽样；相加区间端点不能产生严格的合并区间。人口下推、年龄拆分和补缺作为额外假设记录。

获取步骤见 [WorldPop 技能](../../skills/data_acquisition/01_socioeconomic_natural_change/worldpop/SKILL_ZH.md)和 [GBD 技能](../../skills/data_acquisition/04_integrated_impacts/ihme-gbd-results/SKILL_ZH.md)，对齐后按[健康影响方法](../04_integrated_impacts/health_impacts_ZH.md)计算。
