步骤用于划分研究职责，不强制四步顺序执行；背景资料可以直接供后续阶段使用。跨阶段能力保持共享。第二步仅列概念方法，不含具体数据、参数值、实现代码、项目脚本或执行命令。

历史 YAML 保留早期候选方法和接口设想，不是已验证默认值。其中的数值门槛、输出分辨率、公式及按数据量分支，均不是自动选型或执行规则。需结合数据质量、科学假设、资源、基线和独立验证选择方法，不能只按样本量判断；因果方法还需适当的识别设计。

## 如何使用路径

1. 明确研究问题、范围、所需结果和允许操作。
2. 阅读相关方法，按[四步导航](../../harness/four-step-workflow.md)选择已有技能。
3. 查询真实工具编号及状态，核对输入兼容性和缺少的人工准备。
4. 交接产物前确定上下游字段、单位、时空口径和验收条件。
5. 已支持工具先预检，再按任务授权执行，检查产物和验收依据；流程图不表示已经自动串联。
6. 按[交接指南](../../harness/usage/workflow-handoff_ZH.md)分享脱敏摘要。
