# 如何选择排放核算与治理效率方法

[English](emission_accounting.md) | **中文**

排放清单将明确范围内的活动与源特征转为排放核算。先保持边界一致，地区或时期之间的变化才有可解释的含义。

## 确定清单包含什么

明确源类别、时期、区域、污染物与报告单位。决定核算采用属地生产、消费或其他声明的视角，在解释趋势前说明排除项及重叠类别。

## 让方法与来源信息匹配

活动水平方法和过程方法需要不同的来源信息，应选择证据能够支持的细致程度。分类很细却覆盖不可比，可能使核算差异看起来像真实来源变化。

分开描述活动变化、源特征、技术构成和末端治理，说明各因素如何进入比较，避免同一变化重复计算。

## 一致地解释治理效率

明确分母、所代表的总体，以及不同源类别如何汇总。来源缺失和未开展活动应分别理解。按物理减排定义的效率与受成本约束的效率回答不同问题。

## 复核核算结果

规划来源交叉核对、一致汇总、总量守恒和不确定性分析。变化应能追溯到证据、方法或实际活动的改变，并记录哪些比较仍对覆盖或分类敏感。

[核算技能](../../skills/model/02_emission_inventory/emission-inventory-methods/SKILL_ZH.md)现提供一条经合成验证的直接计算路径。[空间分配](spatial_inventory_ZH.md)、时间谱、垂直排放、化学组分和传输模式导出仍需分别适配。总量检查不等于浓度计算或科学验收。本路径没有使用 MEIC 数据或代码。

## 活动、技术与治理模型

对活动单元 i、技术 t、污染物 p 和互斥治理路线 r：

```text
U_itp = A_i × s_it × EF^0_itp
E_itpr = U_itp × q_itpr × (1 − o_itpr × c_itpr × η_itpr)
E_p = Σ_i Σ_t Σ_r E_itpr
```

| 符号 | 含义与分母 |
|---|---|
| `A` | 指定地区/时期的活动量；燃料质量、产品产量、能源量是不同活动 |
| `s` | 各源技术占该活动量的比例，同一活动内合计为一 |
| `EF⁰` | 实施所建模末端治理前，每单位活动的污染物质量 |
| `q` | 某技术活动分配到互斥治理路线的比例，包含未治理部分；同一技术/污染物内合计为一 |
| `o` | 该路线活动中，治理系统按所述条件有效运行的活动量比例 |
| `c` | 有效运行时，相关废气或排放被捕集送入处理的比例 |
| `η` | 有效运行时，被捕集气流的污染物去除效率 |

该分配模型遵循 [EPA 活动/因子/减排公式](https://www.epa.gov/air-emissions-factors-and-quantification/basic-information-air-emissions-factors-and-quantification)，假设未治理因子和治理汇总代表各路线活动。[EPA 清单指南](https://www.epa.gov/sites/production/files/2017-07/documents/ei_guidance_may_2017_final_rev.pdf)区分捕集、去除效率、有效性和覆盖。这里 `o` 为按活动量加权的运行比例，不自动等同于监管达标率或日历开机时间。

## 安装、运行与设备组合

缺少利用率证据时，设备数或产能安装率不等于处理量覆盖率。只有负荷可比时，运行小时占比才等于活动量加权运行率；否则需用耗料/处理量加权，或细分状态。并行替代方案按互斥路线分配。串联设备只有在各效率适用本设备入口、共同运行/捕集假设成立时，才可采用 `1 − product(1 − η_j)`。不能相加效率、相加重叠安装率，或未经核实假设故障独立；应依据联合运行证据得到路线级汇总，首版计算器不重建此汇总。

若因子已含治理，再乘去除比例会重复扣减。当前脚本只接收明确未治理因子，含治理因子或 CEMS 排放质量需另一条经审查路径；许可浓度限值不是实际排放或排放因子。即使关联同一产品，燃料燃烧、工艺反应和无组织损失也需互不重叠的边界。购入电力和现场燃烧是不同核算。

## 所需数据及候选来源

| 输入 | 可考虑的证据 | 必需检查 |
|---|---|---|
| 燃料/产品/活动 | 统计年鉴、[国家数据](https://data.stats.gov.cn/)、获授权运行记录 | 地域/年份、覆盖、物料或能量口径，与汇总一致 |
| 技术活动份额 | 行业/协会公开统计、工艺调查、技术披露 | 按处理量加权，设备数/产能占比本身不足 |
| 安装与治理路线 | [排污许可平台](https://permit.mee.gov.cn/)公开许可/执行披露、调查 | 污染物、分母、日期及互斥覆盖 |
| 运行与捕集 | 获授权运行/监测汇总或有依据研究 | 活动加权、旁路/停机、捕集与去除分开 |
| 因子/去除率 | 适用官方因子章节、源测试或经审查行业文献 | 技术、燃料/物料、负荷、污染物口径、治理状态、版本和不确定性 |

这些是来源准备选项，不是已实现下载器、已验收全年数据或私人记录访问授权；算例未取得这类真实数据。采用适用的 [EMEP/EEA 章节](https://www.eea.europa.eu/en/analysis/publications/emep-eea-guidebook-2023)；[因子检索器](https://efdb.apps.eea.europa.eu/)规定数值不一致时以章节为准。[IPCC 能源指南](https://www.ipcc-nggip.iges.or.jp/public/2006gl/vol2.html)适用于其温室气体范围，不能自动替代常规污染物因子。

同时规范分子污染物质量与分母活动单位。脚本可换算同维质量/能源单位，没有热值时不将燃料质量变能源量。先核实干基/收到基、产品/原料质量、硫/灰分及污染物表达；以 NO₂ 当量表示的 NOx 不能当作 NO 质量。源类别平均因子不证明某企业实际表现。

## 合成算例与检查

以下数值全部人为构造，仅验证算术，不是实测燃煤因子或真实区域结果。合成 10,000 吨活动，技术 A/B 占 60%/40%；SO₂ 未治理因子为 10/8 kg 每吨。A 的 20% 未治理、80% 路线采用 `o=0.9`、`c=0.95`、`η=0.9`；B 全覆盖，运行/捕集均为一、去除率 0.95：

```text
A: 60000 × [0.2 + 0.8 × (1 − 0.9×0.95×0.9)] = 23064 kg
B: 32000 × (1 − 0.95) = 1600 kg
SO₂: 治理前 92000 kg = 排放 24664 kg + 去除 67336 kg
```

另一套独立合成 NOx 输入得到排放 30,960 kg。不把不同污染物合并为没有定义的总质量。完整输入与执行命令仅在技能维护。

检查占比完整、键唯一、因子/路线覆盖、单位/基准、`治理前 = 排放 + 去除`、明细与分污染物汇总一致。缺少路线不自动等于未治理，输入和失败案例保留。后续不确定性情景应保持份额合计及相关性，首版未实现蒙特卡洛传播。
