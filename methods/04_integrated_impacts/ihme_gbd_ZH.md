# IHME GBD：来源、估计误差与规范化

<!-- README-I18N:START -->

[English](ihme_gbd.md) | **中文**

<!-- README-I18N:END -->

GBD 支持基线健康结局与疾病负担比较；结合暴露前，先明确估计对象、发布轮次和研究人群。人口对齐见[共享方法](../shared/population_health_ZH.md)，获取见 [GBD 技能](../../skills/data_acquisition/04_integrated_impacts/ihme-gbd-results/SKILL_ZH.md)。来源复核日期：2026-10-26。

## 来源与产品身份

GBD 由 IHME 与 全球疾病负担研究协作网络 汇集死亡登记、调查、监测和研究等多种输入，经质量处理与模型估计，形成按地区、年份、年龄、性别和病因等维度的健康指标。**结果工具 的输出是综合估计结果，不是逐人病例记录，也不是全部直接观测的死亡登记数。**

- [官方结果工具](https://vizhub.healthdata.org/gbd-results/)用于筛选和导出。
- [GBD 2023 数据资源](https://ghdx.healthdata.org/gbd-2023)及[输入来源目录](https://ghdx.healthdata.org/gbd-2023/sources)用于追溯资料和版本；结果导出与原始输入来源分别记录。
- 轮次方法可参考 [GBD 2023 人口与全因死亡论文](https://pubmed.ncbi.nlm.nih.gov/41092927/)和[病因、伤残及风险研究](https://doi.org/10.1016/S0140-6736(25)01637-X)。具体指标按对应论文及附录核对，不将一项指标的方法套到全部产品。

本轮网页页脚已观察到 GBD 2023。研究年份和发布轮次是两件事：GBD 2023 中的 2020 年估计不等于 GBD 2021 中的同年估计。采用一致轮次覆盖研究期；跨轮次变化先查方法与输入修订，不能简单解释为真实健康变化。

选择产品和下载范围时，先看[可获取数据表与分级下载计划](ihme_gbd_availability_ZH.md)，其中分别标注官方产品、当前适配器及真实获取状态。

数据用途、许可、引用及导出要求以 [IHME 数据使用条款](https://www.healthdata.org/data-tools-practices/data-practices/terms-and-conditions)和当前产品页面为准，不把方法论文的开放许可等同于所有输入数据或结果的无限使用许可。需接受条款或登录时由本人完成，不共享账号、验证码、会话信息或任务下载链接。

## 指标和维度怎样区分

| 项目 | 含义与规范 |
|---|---|
| 数量 | 对应指标的数量，如死亡人数或 DALYs；可能为非整数估计，不逐行取整后再计算 |
| 率 | 核对分母和单位；GBD 常见按每 100,000 人表达，仍需以具体产品和指标说明为准 |
| 百分比 | 核对分母及数值编码是 0–1 比例还是 0–100；不要只因中文名称就再乘或除 100 |
| 年龄别、全年龄、年龄标化 | 是不同统计对象。年龄标化率用于消除年龄结构影响，不能直接乘实际人口还原死亡数；全年龄粗率也不能替代年龄别率 |
| 全因、父病因和子病因 | 层级可能重叠，不把全因与子项相加，不把不互斥的父子病因合计 |
| 性别/地区 | 两性合计不再与男、女相加；全球/地区/国家及下级行政区不重复叠加 |
| 病因死亡与风险归因 | 病因死亡是基线结果；污染风险归因需要相应风险维度和比较风险框架，不能把“卒中死亡数”直接称为 PM2.5 归因死亡 |
| 人口与 `population_group` | 参数中的 `population_group` 不是“返回人口人数”的开关。人口分母需要对应产品/渠道和维度核对，不能由病因死亡请求或已存在的数据声明推断已实现人口导出 |

## 误差与不确定性

- 输入资料的覆盖、漏报、诊断/死因编码和登记质量不一；资料稀少地区更依赖模型和跨时空信息。
- 病因归类、不可用编码处理、协变量、统计模型、人口分母和轮次更新会影响估计及可比性。
- `val`、`lower`、`upper` 应一起保留。GBD 报告的不确定区间不简单等于一次抽样调查的置信区间，不能只凭区间宽度还原全部输入误差。
- 汇总、差值或比值的不确定区间需要正确传播联合不确定性；仅有上下界时，不将“下界相加/上界相加”当作严格合成不确定区间，也不假定不同病因或年份完全独立。

不确定度的构造按具体轮次与指标查原文；例如 [GBD 2023 死因论文](https://doi.org/10.1016/S0140-6736(25)01917-8)说明了其 95% 不确定区间 的分位数方法。这里不为全部 GBD 产品固定同一抽样次数或误差比例。

## 规范化与检查顺序

1. **固定查询契约**：记录轮次、上下文、研究年份、地区、病因/风险、年龄、性别、`measure` 和 `metric` 的 ID 与标签；选少量维度先验证。历史 ID 样例只作语法参考。
2. **核对估计对象**：返回的轮次与全部维度须对应研究契约，不能把旧查询或不同口径的记录混入同一分析。
3. **保留原导出**：在新任务原文件目录保存文件与非秘密请求记录、取得时间和校验摘要；派生表另存，不覆盖已下载数据。不得把账户/邮件或临时下载链接放入共享记录。
4. **明确字段和唯一键**：常见字段包括 `measure`、`location`、`sex`、`age`、`cause`、`metric` 的编号与名称，以及 `year`、`val/lower/upper`；实际字段结构以导出文件为准。唯一键包含轮次、上下文与全部适用维度，不依赖列顺序或中文译名推断 ID。
5. **内容核验**：比较请求与实际标签/ID、记录数和缺失组合；检查数值可解析及有限、`lower ≤ val ≤ upper`。缺行不等于零，合法单位和非负范围依指标确认；仅作结构检查不能证明模型准确。
6. **人口与年龄配准**：明确年龄边界、开口年龄组、婴幼儿组和人口分母。不要由排序位置硬映射年龄；如需按年龄合并，使用相容人数/分母与加权规则，不平均年龄别率冒充总率。
7. **下游使用**：风险函数所需年龄别基线率与相应人口、浓度和病因口径对齐。WorldPop 与 GBD 人口不是自动一致的分母，需解释总量、年龄结构和参考时点差异。
8. **跨期与缺失**：优先同轮次取完整研究期。确需补充、插值或跨轮次衔接时，另写方法与标记，不按旧项目的某个年份切点通用拼接。

结果进入健康影响计算前，还需按[健康情景方法](health_impacts_ZH.md)核对风险函数和情景设计。步骤、当前网页验证状态与人工操作见[首次获取向导](../../skills/data_acquisition/04_integrated_impacts/ihme-gbd-results/references/first-download-guide_ZH.md)。
