# 解释 GCAM 情景输出

[English](gcam.md) | **中文**

GCAM 将社会经济假设、能源与土地系统、技术及气候政策连接为内部一致的情景。比较基准与干预时，应固定模型版本、地区定义及报告年份。情景差值以模型假设为条件，不等于经验识别的因果效应。

## 准备模型实验

先选择模型变体、版本及科学上要改变什么，再决定软件操作。未修改且兼容的发行包可以使用自带二进制和 XML。改变 C++ 行为需要源码编译，改变数据系统的处理可能需要重建匹配的输入 XML。这些操作针对模型的不同部分，不能相互替代。

1. 明确问题、基准与干预、模拟时期及产物，记录哪些假设保持相同、哪些发生变化，将模型、输入及二进制身份一起保留。
2. 选择兼容发行包或固定版本构建，分别核对运行环境与科学假设。构建成功不证明输入或校准正确。
3. 准备独立任务副本，明确配置、输入引用、日志及输出位置。配置名和相对路径取决于所选分支。保留原情景，避免多个任务同时写同一数据库。
4. 运行要求的实验，检查进程退出状态、要求时期是否完成、求解失败和数据库写入情况。看似成功的信息不足以证明数值运行成功。
5. 解释情景差异前，检查校准、核算一致性、地区与时间覆盖，以及相关假设的敏感性，将技术完成与科学验收分开。

已有 XML 不必为每个实验重新生成。重建输入可能改变校准与数据来源，因此必要时记录受影响模块和生成版本。原生模型输出保留任务身份；经检查及人工审核后，选定衍生成果才可登记复用。命令、平台差异、存储位置和人工适配项见[编译运行参考](../../skills/model/04_integrated_impacts/gcam/references/build-and-run_ZH.md)。

## 数量、价格与组件

提取前先确定对象：市场价格、部门产出、物理需求还是技术成本/投入组件。名称相似的 XML 节点未必分母相同。相乘前核对价格单位、数量单位、货币基年及聚合层级。模型价格不能自动解释为实际交易价或已验证的企业治理单位成本。

技术组件和取决于模型核算边界及系数。区分能源/材料投入、非能源成本和产出单位，避免中间投入重复计费或将所有组件视作独立支出。衍生指标保留源节点标签。

## 区域比较

GCAM-China 与官方 GCAM-Core 的地区和部门结构不同，省码需按所选发行包映射。省级汇总排除 China/Global 聚合行，并显式报告缺省。全国数量只能在单位兼容、互不重叠时求和；全国价格仅在权重及分母兼容时才可按数量加权，零权重需明确解释。

配对情景保持相同地区及部门。分别报告结构、数量及单位价变化；固定年份比较不能说明完整时间路径。插值和缺年假设需可见。

## 证据与限制

检查情景/年份/地区覆盖、唯一行、单位、非有限值及组件闭合，保留基准/干预配对和来源。输出检查只验证数据库访问及结构；提取和绘图不证明求解收敛、校准质量或科学验收。

命令、配置、产物及编译排错统一见 [GCAM 技能](../../skills/model/04_integrated_impacts/gcam/SKILL_ZH.md)。没有模拟启动器；编译及配置修改仍为人工任务。历史专门参考提供[模型差异](../../skills/model/04_integrated_impacts/gcam/references/gcam-china-vs-official.md)及[单位解释](../../skills/model/04_integrated_impacts/gcam/03_data_extraction/references/price-unit-interpretation.md)。
