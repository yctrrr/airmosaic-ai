# 公开演示资产

[English](README.md) | **中文**

本目录只保存合成数据、参考结果及其公开元数据，是仓库的资产入口。真实数据与新生成结果保存在 `AIRMOSAIC_ASSETS_DIR` 指定的仓库外私人资产根目录。

- 数据：`data/<stage>/<actual-dataset-name>/<version>/`。
- 参考结果：`results/<toy-project>/<reference-run>/<stage>/<tool_id>/`。
- 私人任务在配置的外部根下沿用相同逻辑结构。
- 项目配置跨阶段引用同一数据版本，不重复复制。

[toy-manifest.json](toy-manifest.json)明确列出允许读取的演示 CSV 及内容哈希。执行器接受仓库相对 `assets/...` 输入，核对内容并保持只读；拒绝未登记文件、变更后的演示内容、软链接及目录联接。公开参考结果不证明真实数据或科学验收通过。

四行演示使用合成标签和无量纲示意值。预期结果排除两行汇总记录，将其余权重加总为 3，加权均值为 40/3。这不是原始观测、正式数据集或校准模型结果。操作见[演示流程](../harness/usage/toy-demo_ZH.md)。

实际位置只放在 Git 外的个人配置中，[路径模板](../config/examples/asset-paths.example.json)用于说明字段。JSON 不会自动加载；请显式设置三个变量或审查后使用环境助手。这是配置引用，不是文件系统链接，也不建立另一套数据存储。凭据和浏览器状态继续独立保存。

新结果始终写入配置的私人资产根。该根缺失或位于 Git 内时返回错误，不回退到这里保存真实输出。Git 忽略规则只放行明确的公开文件。遵循[资产与复核规范](../harness/assets_ZH.md)。
