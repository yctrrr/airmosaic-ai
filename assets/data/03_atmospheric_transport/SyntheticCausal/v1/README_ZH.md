# 因果合成示例 v1

[English](README.md) | **中文**

全部 600 行均为生成示例，不是环境观测或个人数据。固定生成种子为 20261027，以独立标准正态随机变量定义：

```text
treatment = 0.8*x1 - 0.6*x2 + u
outcome = 2*treatment + 1.2*x1 + 0.7*x2 + e
```

已知部分线性处理斜率为 2，训练、验证、测试分别为 400、100、100 行。`group_id` 是测试分组折分的人工数值标签，不是真实空间编号。公开演示清单记录文件哈希，通过回归技能使用[因果示例配置](../../../../../config/examples/ml-regression/synthetic-causal.json)。模型产物放在被忽略的本地结果或已授权外部项目根，不写入此只读示例目录。
