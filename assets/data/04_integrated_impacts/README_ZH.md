# 阶段数据导航

[English](README.md) | **中文**

每份数据只有一处主要归属，跨阶段引用固定版本。公开输入限清单声明的合成文件或明确授权且附许可的公开数据副本，私人数据保存在配置的外部资产根。

参见[资产入口](../../README_ZH.md)。

暴露反应来源参数放在外部 `${AIRMOSAIC_ASSETS_DIR}/data/04_integrated_impacts/ExposureResponse/<dataset-version>/`，与人口、暴露及基线死亡率分开。来源版本、适用性和校验见[健康方法](../../../methods/04_integrated_impacts/health_impacts_ZH.md)与[技能](../../../skills/model/04_integrated_impacts/health_impact_analysis/SKILL_ZH.md)。公开的来源说明不代表取得附件再分发许可，也不授权直接开展健康计算。
